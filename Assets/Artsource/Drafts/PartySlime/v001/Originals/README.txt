Hunter Grandma - Party Slime Zombies Aseprite Import Bundle

This bundle contains 10 transparent PNG sprite sheets prepared for import into Aseprite.
They are NOT native .aseprite files.

Suggested import workflow in Aseprite:
1. File > Open each PNG
2. Sprite > Slice or use the grid at 4 columns x 4 rows
3. Each frame is intended for 120x120 use, but the generated sheets may need cleanup/cropping/palette refinement.
4. Suggested motion groups by frame order:
   Row 1 = idle variations
   Row 2 = walk
   Row 3 = attack
   Row 4 = pop/death
