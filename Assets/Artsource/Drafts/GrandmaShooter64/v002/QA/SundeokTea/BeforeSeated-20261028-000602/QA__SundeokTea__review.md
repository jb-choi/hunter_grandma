2026-10-28. 편집 정본은 `../../grandma_04_sundeok_tea.aseprite`다.

## 제작

기존 v002 순덕 정본의 머리/파마머리·얼굴 보정·꽃무늬 몸빼·신발 픽셀을 가져왔다. 총과 기존 발사 자세의 팔을 제거하고 겨자색 조끼 몸통, 굽힌 양팔, 찻잔과 손, 김을 Aseprite의 네이티브 이미지/레이어 API로 직접 작화했다. 고해상도 생성 이미지 축소 방식은 사용하지 않았다. 기존 원본과 게임 스프라이트는 수정하지 않았다.

## 파일 검사

- 저장 native 재개봉: 64×64 RGB, 1프레임/100ms, 9개 표시 레이어, `tea_sip` 태그.
- 원본과 같은 팔레트 33슬롯, 불투명 사용색 25개. 팔레트 밖 픽셀 0, 부분 알파 0.
- 저장 native의 합성과 대응 투명 PNG의 차이 0픽셀.
- 전체 불투명 bounds `(4,3,46,58)`, 발 마지막 행 y60.
- 각 레이어의 실제 표시 상태를 바꾼 18개 native를 저장·재개봉하고 실제 visible 값을 확인했다. 검사 후 전체 표시 합성도 원래와 일치한다. 최종 정본은 모든 레이어 표시 상태다.
- 입력 SHA-256 사전/사후 일치는 `source_hashes_before.json`, `source_preservation.json`을 따른다. 추가 결과 해시는 `delivery_hashes.json`에 별도로 기록한다.
