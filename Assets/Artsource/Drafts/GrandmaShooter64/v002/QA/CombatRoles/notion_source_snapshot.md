# 1. 플레이어에게 보이는 성장 경험

1. 처음에는 <b>샷건 할머니 1명</b>만 실제 화면에서 전투한다. 다른 할머니 슬롯은 <b>검은색 실루엣 + 자물쇠</b>로 노출한다.
2. 스테이지에서 일반 독립 감염체를 처치하면 보상을 얻는 안(재화 명칭·종류·획득 방식 미정)을 검토하고, 마지막 숙주형 보스를 제압·수레에 태워 돌아온다.
3. (미정)재화·추가 재료(도입 여부 미정)를 모아 현재 할머니의 스탯과 무기를 강화한다.
4. 조건을 충족하면 잠겨 있던 다음 할머니가 <b>실루엣에서 컬러 캐릭터로 바뀌는 연출</b>과 함께 합류한다.
5. 새 할머니가 가져오는 <b>새 공격 방식 또는 운송 기능</b>이 화면에 추가되어 이전보다 강하고 화려한 전투단이 된다.
6. 해금한 할머니와 각자의 무기를 계속 키워 다음 스테이지를 돌파한다. 이전 스테이지 반복 사냥·보스 포획이 파밍 루프를 담당한다.

<b>차별화할 핵심:</b> 수치가 오르는 것뿐 아니라 <b>검은 캐릭터 카드가 컬러로 열리고 실제 전투 화면에 새로운 할머니가 나타나는 순간</b>을 큰 성장 보상으로 만든다.

# 2. 동료 할머니 라인업 (역할 콘셉트 확정, 세부 성능 초안)

| 할머니 | 전투/지원 역할 | 화면에서 읽힐 액션 | 성장 후보 |
| --- | --- | --- | --- |
| <b>샷건 할매</b> | 초기 주력, 근·중거리 산탄 | 발사 반동, 다수 적 넉백, 근거리 정리 | 공격력, 발사 간격, 산탄 범위, 제압력 |
| <b>화방 할매</b> | 근거리 범위 지속 공격 | 전방 부채꼴 화염, 화염 지속 | 화염 범위, 지속 피해, 연료 효율 |
| <b>기관총 할매</b> | 다수 적 지속 제압 | 연속 총성과 탄막, 발사 리듬 가속 | 연사력, 탄량, 관통/넉백 |
| <b>저격수 할매</b> | 원거리 고화력·보스 압박 | 조준 후 단발, 강한 피격 강조 | 단발 위력, 사거리, 조준 시간 |
| <b>운송 할매</b> | 포획 보스 회수·운반 지원 | 수레를 밀고 접근, 거대 보스 적재·귀환 | 수레 용량, 운반 속도, 회수 효율 |

- 위 유형의 <b>존재와 캐릭터 차별화</b>는 새 콘셉트로 반영. 수치·특수효과·전투 참여 순서까지 확정된 것은 아님.
- 운송 할매는 <b>지원형 동료</b>로 보는 것이 자연스럽다. 직접 사격을 반드시 하게 만들지 않으며, 포획·수레 루프에 기여하도록 설계한다.
- 기존 숙주형 보스는 <b>사망이 아니라 제압 후 포획</b>된다는 규칙 유지. 화염방사기 등 공격 이펙트가 보스 사망으로 오인되지 않도록 연출 분리.
- 동료들끼리 서로 다른 무기를 쓰더라도 플레이어가 스테이지마다 상성/조합 퍼즐을 풀게 하지 않는다. <b>해금 및 누적 강화로 자동으로 더 잘 싸우는 전투단</b>이 기본.

<b>설계 원칙:</b> 할머니 레벨과 무기 레벨을 하나로 합치지 않는다. 할머니는 <b>누가 얼마나 숙련됐는지</b>, 무기는 <b>무엇을 들고 얼마나 강력하게 공격하는지</b>를 담당한다. 무기 성능과 할머니 개인 스탯이 최종 전투 성능에서 합쳐진다.

<b>초기 단순화 제안:</b> 캐릭터와 무기는 일대일로 고정(샷건 할매↔샷건 등)하고, <b>무기 교체/장비 세트</b>는 추후 검토. 캐릭터 수×무기 수의 조합을 처음부터 만들면 기획·밸런스·도트아트 부담이 커진다.

# 4. 스탯 구조 — 할머니 강화 vs 무기 강화 (모두 초안)

## 4.1 할머니 스탯

| 스탯 후보 | 의미 | 플레이 체감 |
| --- | --- | --- |
| 숙련도 | 자신의 무기를 더 효율적으로 사용 | 같은 총을 들고도 더 빠르고 정확하게 공격 |
| 공격 숙련 | 캐릭터 자체의 공격 기여 | 기본 피해 보정 |
| 생존력 | 피격 버티기 | 출정 실패율 감소 |
| 제압 숙련 | 숙주형 보스 무력화 지원 | 보스 제압까지 걸리는 시간 감소 |
| 운송 숙련(운송 할매 중심) | 적재·귀환 능력 | 회수 처리 시간이 짧아짐 |

처음부터 5개를 전부 UI에 띄우지 말 것. <b>대표 레벨 1개 + 역할별 핵심 스탯 1\~2개</b>로 시작하고, 세부 원천값은 내부 데이터로 관리하는 안 검토.

## 4.2 무기 스탯

| 무기 | 강화 후보 | 뚜렷한 시각 효과 |
| --- | --- | --- |
| 샷건 | 공격력·발사 간격·산탄 폭 | 한 발에 더 많은 좀비가 밀려남 |
| 화염방사기 | 지속 피해·범위·유지 시간 | 불길이 길고 넓게 유지됨 |
| 기관총 | 연사·탄량·관통 | 끊기지 않는 탄막 |
| 저격총 | 단발 피해·사거리·관통 | 큰 적에게 강한 단발 피격 |
| 수레 | 운반속도·적재능력 | 수레 동작과 적재 모습 변화 |

<b>중복 주의:</b> 개인 공격력과 무기 공격력을 모두 성장시키되, 둘이 완전히 같은 버튼이라면 의미가 없음. 비용·성장 곡선·해금 시점·시각적 체감 중 적어도 하나가 달라야 한다.

# 5. 재화 → 업그레이드 → 전투력 연결

| 자원 종류 | 획득처(안) | 소비·사용처(안) | 역할 |
| --- | --- | --- | --- |
| <b>(미정)재화</b> | 획득처 미정(현행 프로토타입은 일반 좀비 사살·스테이지 보상) | 소비처·비용 미정(기본 강화 재화로 쓰는 안) | 재화 명칭·유형·수량 체계 확정 전 UI 자리표시자 |
| <b>(미정)추가 재료</b> | 추가 자원 도입 여부 및 획득처 미정 | 승급·구간 돌파 등에 쓰는 안(미정) | 별도 재화를 반드시 도입한다는 뜻 아님 |
| <b>누적 포획 기록</b> | 스테이지 반복 클리어·숙주형 보스 포획 | 할머니 해금 또는 달성 조건(소비 아님) | 장기 목표·전진 동기 |

- <b>재화 수 확정 아님.</b> 출시 초기에 같은 역할의 재화를 여러 종류로 복제하지 않는다.
- '해금 조건 충족'과 '해금 비용 지불'은 구분해야 한다. 포획 횟수를 기록하는 것과 포획한 사람을 소비해 동료를 구매하는 것은 전혀 다른 경험이다.
- <b>기존 전투 보상안과의 관계:</b> 기존 프로토타입은 일반 좀비 처치·용해 후 '골드'를 지급하지만, 최종 재화 명칭·획득처·소비처는 <b>(미정)</b>. 숙주형 보스는 제압·포획하며 포획 대상을 재료나 희생 비용처럼 쓰지 않는 방향을 권장.

## 5.1 성장 연산의 구분

1. <b>반복 강화:</b> (미정)재화 소비(예시) → 샷건 피해량 +n, 기관총 발사 간격 감소 등.
2. <b>단계 승급:</b> 특정 재료와 조건 충족 → 무기 등급 한 단계 상승, 신규 효과/외형 변화.
3. <b>캐릭터 해금:</b> 잠긴 할머니 카드 → 컬러 전환 + 출전·지원 기능 활성화.
4. <b>영구 기록:</b> 스테이지 최초 클리어, 보스 포획 누적 등. 캐릭터 해금 조건/마일스톤으로 활용 가능.

# 6. 동료 해금 UI·연출

## 6.1 할머니 도감/편성 화면

- 카드 정렬은 <b>샷건 / 화방 / 기관총 / 저격 / 운송</b> 순서를 <b>레이아웃 예시</b>로 사용하되 실제 해금 순서는 후속 결정.
- <b>미해금:</b> 검은색 실루엣(캐릭터 실루엣과 대표 무기 형태가 어렴풋이 보임) + 자물쇠 + 해금 진행도. 능력·상세 스탯은 일부 또는 전부 숨김.
- <b>해금 가능:</b> 실루엣 테두리 강조, 해금 버튼/자동 해금 알림. 다음 조건을 명확히 보여주되 강제 과금이나 랜덤 뽑기를 기본 전제로 하지 않음.
- <b>해금 연출:</b> 자물쇠 해제 → 어두운 실루엣이 밝아짐 → 컬러 스프라이트/무기 공개 → 할머니 특유의 동작 → 전투단 합류.
- <b>해금 후:</b> 컬러 카드, 레벨/주요 스탯, 전용 무기 강화 버튼, 전투 등장 상태.
- <b>벨트스크롤 연동:</b> 실제 2D 벨트스크롤 전투에 합류한 할머니를 눈으로 볼 수 있어야 한다. 좌우 전진과 화면 깊이(Y) 이동 시 서로 완전히 겹치지 않도록 위치·발 위치 정렬 설계.

## 6.2 비주얼 훅과 비용

해금 전 실루엣은 단순한 회색 플레이스홀더가 아니라 <b>무기 형태만으로 다음 캐릭터를 궁금하게 만드는 카드</b>여야 한다. 잠금 상태 아트는 완성된 캐릭터 스프라이트를 어둡게 마스킹해 재사용하는 안을 우선 검증한다. 해금 후에는 색상뿐 아니라 <b>새 공격 소리·공격 애니메이션</b>도 함께 열려야 화면 변화가 커진다.

```txt
  → 일반 좀비 사살: (미정)재화 획득(예시; 지급 규칙 미확정)
  → 숙주형 보스 제압·포획: 클리어 및 누적 포획 기록
  → 샷건 할매 스탯·샷건 강화
  → 특정 진척/조건 달성: 화방 할매 해금
  → 검은 실루엣 → 컬러 캐릭터 + 벨트스크롤 전투 합류
  → 광역 화력 증가 / 다음 Stage 돌파
  → 이후 기관총·저격·운송 할매 등 차례로 합류
```

<b>중요:</b> 위 '화방 할매가 첫 번째 해금'은 설명용 예시이지 확정 순서가 아님. 기존 <mention url="https://app.notion.com/p/4047313398e0818db924d95c5c455419" />의 스테이지별 보스 반복 포획 루프는 그대로 유지.

# 8. 밸런스·개발 제약

- <b>화면 복잡도:</b> 동료가 5명 모두 동시에 출전하면 적·탄막·화염·수레가 겹쳐 64×64 픽셀 아트에서 가독성이 깨질 수 있다. 최대 동시 출전 인원은 테스트로 결정.
- <b>방치형 적합성:</b> 플레이어가 모든 할머니에게 목표 지정·재장전·포지션 명령을 내리는 게임으로 변하지 않게 한다. 기본값은 자동 전투/자동 운송을 검토.
- <b>벨트스크롤 이동:</b> X/Y 좌표와 발 위치 기반 정렬, 역할별 사거리·깊이(Y) 차이 명중 판정 테스트.
- <b>성장 폭주:</b> 할머니 5명 레벨과 무기 5개 레벨이 독립적으로 늘어나면 강화 화면이 과밀해질 수 있다. '할머니 카드 안에서 해당 무기 강화'로 묶되 성장값은 분리하는 방식 추천.
- <b>수치와 영상의 일치:</b> 공격력 +5%로 체감이 미미한 구간보다 '한 발에 녹이는 적 수 증가', '합류 인원 증가', '수레 실루엣 변화'처럼 눈에 보이는 전환점을 우선 검증.

# 9. MVP 범위 및 미결정 의사결정

## 9.1 첫 프로토타입 후보

- [ ] 샷건 할매 1명 + 잠금 실루엣 카드 1명(다음 할머니)
- [ ] (미정)재화 획득(가정) → 샷건 할매 개인 강화 1종 / 샷건 무기 강화 1종
- [ ] 조건 달성 → 카드 컬러 전환 → 두 번째 할머니 전투 합류
- [ ] 두 할머니가 2D 벨트스크롤에서 자동으로 좀비를 사냥
- [ ] 기존 일반 좀비 처치 보상(현재 프로토타입 골드)을 (미정)재화 가안으로 취급하고, 보스 제압·포획 루프는 유지
- [ ] 확대 단계에서 기관총·저격·운송 할매 추가

## 9.2 미결정

1. 해금은 <b>최초 스테이지 클리어 / 누적 포획 / 재화 구매 / 혼합형</b> 중 무엇을 기준으로 할지?
2. 해금한 할머니는 <b>전원 자동 출전</b>인지, 출전 슬롯을 선택할지?
