# 05–08 역할 변경 · 화방/기관총/저격/오토바이

2026-10-28. 새 편집 정본 네 개는 v002 루트의 `grandma_05_flamethrower.aseprite`, `grandma_06_machinegun.aseprite`, `grandma_07_sniper.aseprite`, `grandma_08_motorcycle.aseprite`다. 기존 05–08 정본과 순덕/차 마시기 파일은 보존했다.

## 최신 수정 · 무기 확대와 특징 강화

사용자 요청 “조금더 무기 사이즈를 키우고 특징을 살려줘”를 반영했다. 이전 38개 납품 파일의 해시를 비교해 모두 이전 납품과 같음을 확인하고, `BeforeLargeGear-20261028-111618`에 원본·PNG·스크립트·문서·검수 결과를 보존했다. 현재 재현 스크립트는 `../../Scripts/enlarge_combat_gear.lua`이며 `backup`에 보존 폴더를 지정한다.

- 05: 연료통·압력계·황동 노즐을 키우고 기존 작은 섬광을 넓어지는 부채꼴 화염으로 바꿨다. 연결 호스와 양손을 새 장비 크기에 맞췄다.
- 06: 총 본체를 키우고 냉각된 다중 총열, 앞쪽 회전 고정 링, 대형 드럼 탄창, 급탄 벨트로 지속 연사 역할을 강조했다.
- 07: 개머리판·조준경·대물 렌즈를 키우고 긴 총열, 총구 제퇴기와 펼친 양각대를 강조했다.
- 08: 바퀴 반지름을 7→8px, 앞 바퀴 중심을 (49,53)→(51,52)로 조정하고 V형 엔진·이중 배기구·운송 가방·짐받이/침낭을 보강했다. 커진 엔진 앞 발판의 부츠도 복원했다.

[직전 버전과 비교](../../Previews/combat_roles_weapon_size_before_after_4x.png) · [장비 레이어 불투명 픽셀 수](gear_size_metrics.json). 장비 레이어의 픽셀 수는 각 198→357, 245→539, 169→375, 508→675다. 이 수치는 가로 길이나 확대 배율을 뜻하지 않으며, 무기/장비 자체의 면적이 증가했음을 확인하는 검사다. 네 파일 모두 몸통·머리·먼 팔·가까운 팔(2/3/4/6번 레이어)은 보존본과 픽셀 차이 0을 검증했다. 연료통/차량, 장비, 손/세부, 효과 레이어를 수정했다.

## 요청과 근거

[기획서_02](https://app.notion.com/p/4067313398e08130965aebafbb62a76d)에서 화방의 전방 범위 화염, 기관총의 지속 제압/탄막, 저격의 긴 사거리/단발, 운송의 지원 역할을 읽었다. 기획서 수레 대신 오토바이를 사용한 것은 이번 사용자의 명시적 요청이다. 게임 수치·해금 순서·추가 전투 로직을 이 아트 작업에서 결정하지 않았다. [읽은 페이지 스냅샷](notion_source_snapshot.md).

## 제작 범위

기존 native의 머리·색상·의상 픽셀을 재사용하고 Aseprite Lua 이미지/레이어 API로 무기, 연결 팔과 손, 효과를 직접 작화했다. 08은 카우보이 모자/얼굴/땋은 머리를 유지하고 몸통·굽힌 하체·오토바이를 새로 그렸다. 이미지 생성/고해상도 축소 방식은 사용하지 않았다. 신규 파일은 구별되는 역할 이름을 사용한다. 작업 중간본은 `InitialPass`에 있고 편집 정본이 아니다.
