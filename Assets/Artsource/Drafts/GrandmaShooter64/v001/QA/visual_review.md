# HG-BASE64 v001 시각 검수

검수일: 2026-10-21. 대상: 루트의 후보 3개 `.aseprite`, 각 1프레임·7레이어. 파일 해시는 [delivery_hashes.json](delivery_hashes.json)을 따른다.

표시 상태는 Aseprite Lua로 실제 `isVisible`을 전환해 상태별 native를 저장하고 **다시 열어** 렌더했다. 전체 기본 표시 상태는 7개 모두 표시다. 정본은 QA 중 다시 저장하지 않았으며 상태별 native는 `LayerReview/States/`, 픽셀·표시 상태 기록은 [native_validation.json](native_validation.json)에 보관한다.
