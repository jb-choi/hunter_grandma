## 기술 검수

| 검사 | 결과 |
| --- | --- |
| 파일 규격 | 두 후보 모두 64×64 / 1F / 4L / shoot_base / 100ms |
| native와 발사·효과 없음 PNG | 총4개 비교, 픽셀 차이0 |
| 팔레트·알파 | 33슬롯, 실제사용28/26색, 부분알파0, 팔레트 밖 색0 |
| 단독/숨김 | 전16개 상태 저장·재개봉과 전4개 시트 시각 확인 |
| 기본 표시 복원 | 기본 4개 visible, 합성 복원 차이0, QA 정본 미저장 |
| 이전 후보 보존 | v002의04~08 원본 SHA-256 사전/사후 일치 |
| 사용자 선호/최종 나이 인식 | 승인 전, 기술 검수와 구분 |
| Unity 연결·연속 동작 | 이번 범위 해당 없음 |
