## 작화 확인

[실제120px](../Previews/v2_set_native.png), [2배 포즈](../Previews/v2_set_2x.png), [밝음/어두움](light_dark_2x.png), [장전 solo/hidden](f35_solo_hidden_2x.png)을 시각 확인했다. 회색 곱슬머리·안경·깔깔이·꽃무늬 바지·와인색 신발이 이어진다. 이전 큰 보폭 대신 발을 모으고 뒤꿈치가 올라가는 작은 걸음으로 바꿨다. 탄 삽입 손동작과 몸통 압축, 짧은 사격 반동과 별도 섬광이 구별된다. 팔/무기를 숨기면 복원된 깔깔이 몸통이 남는다.

장전·발사 생성 원화의 비례 차이를 발견해 최종본에는 쓰지 않고 연구 원화로 보관했다. 최종은 새 보행의 같은 Body 준비 자세에 native 압축/반동을 적용해 일관성을 맞췄다. 처음 보행 보완 이미지에 남던 배경 알파는 Built-in ImageGen 배경 추출 후 다시 샘플링했다.

게임 런타임은 기존27프레임/v1 그대로이며 Unity Clip/Animator 전환이나 게임 실화면 테스트는 수행하지 않았다. 이전 보행과의 비교 GIF는 왼쪽이 이전 넓은 v2, 오른쪽이 이번 좁은 보폭이다. Reload/Fire 비교의 왼쪽은 기존 v1, 오른쪽은 v2이며 비교 양쪽은 새 동작의 프레임 시간으로 맞췄다.


## Unity 연결 후속 · 2026-11-02

위 원화 제작 검수 이후, 사용자 요청의 Walk/Aim/Fire를 Unity에 연결했다. master28–33 / master40 준비 자세 유지 / master40–43을 사용한다. 원본43프레임과7파츠 라이브러리 해시는 유지했다. 게임용11포즈/33PNG 및 Body+Upper 재합성은 픽셀 차이0이다. 이동 조준은 전술 원화의 상체 이동값과 일치하고, 발사의 독립 반동은 유지한다.

Unity6000.3.10f1의 격리·출력 음소거 batch 검사에서 애니메이션42개, 장전음28개가 통과했다. 걷기/이동 조준/이동 발사/왼쪽 발사를 RenderTexture로 캡처해 확인했다. native Game View/플레이어 빌드 검수는 미실시다. [게임 연결 상세·증거](../../../../../../../Docs/Sundeok-TacticalV2-Integration.md). 원화 제작 당시 runtime_changed=false 기록은 해당 시점의 스냅샷으로 남긴다.
