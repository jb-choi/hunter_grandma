# v002 귀여운 슬라임 인간형

사용자 피드백: “으 너무 징그러워 좀 귀여운 느낌이 나게 v002”.

- 사람의 머리·몸통·양팔·양다리와 슬라임 재질을 유지한다.
- 약3~3.5등신의 성인 SD 비율, 둥근 볼·작은 반짝이는 눈·작은 코와 닫힌 입, 짧고 말랑한 손발로 바꾼다.
- 민트 일반형 / 피스타치오색 통통한 대형 / 따뜻한 얼굴과 겨자색 평상복 위 청록 코팅의 구조 대상.
- 외곽선과 명암 덩어리를 단순하게 만들고 반사광과 기포만으로 젤리 느낌을 살린다.
- 움푹 팬 눈·해골 턱·이빨·갈비뼈·힘줄·날카로운 손·근육 덩어리·길게 늘어지는 점액을 제거한다.
- Idle4 / Walk6 / Run6 / Attack6 / Dead6, 종별28포즈,120×120을 유지한다.
- 사냥종 Dead는 말랑한 젤리 웅덩이, 인간형 Dead는 피격 후 옆으로 누운 채 점액이 조금만 벗겨지는 상태다.
- 기존 `../Monsters`와 순덕/오토바이 원본은 보존한다. 새 정본은 이 `Monsters_Cute`에 둔다.

## 인간 구조 대상 전신 코팅 수정

사용자 요청에 따라 기존 v002 파일에서 청록 점액을 머리·양어깨·가슴/배/등·허리/골반·양팔/양손·양다리/무릎/발목/신발까지 이어지는 전신 외피로 늘렸다. 따뜻한 얼굴 일부와 겨자색/남색 의상 패치를 남겨 실제 사람이 안에 있음을 읽히게 한다. 귀여운 표정과 포즈, 120px/28프레임/5동작 구조를 유지한다. Dead는 피격 반동 후 넘어져 누워 끝나고 대부분의 코팅이 남는다. 누운 자세에 맞춰 코팅 없는 몸체도 복원한다.

## 얼굴 절반·피격 후 누운 Dead

사용자의 최신 수정이 이전 완전 코팅 해제/무릎/도움 손 동작을 대체한다. 얼굴 한쪽 눈·볼·턱까지 청록 점액이 가리며 반대쪽 얼굴은 드러난다. Dead6은 피격 반동→무릎 풀림→뒤/옆으로 넘어짐→착지→누워 안정→누운 상태 유지다. 마지막에는 어깨/가슴 일부의 슬라임만 벗겨지고 대부분은 몸에 남는다. 인간 몸체를 점액 웅덩이로 녹이거나 없애지 않는다.
