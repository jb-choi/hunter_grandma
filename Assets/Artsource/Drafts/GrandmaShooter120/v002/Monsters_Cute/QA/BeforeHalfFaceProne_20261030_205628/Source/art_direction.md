# v002 귀여운 슬라임 인간형

사용자 피드백: “으 너무 징그러워 좀 귀여운 느낌이 나게 v002”.

- 사람의 머리·몸통·양팔·양다리와 슬라임 재질을 유지한다.
- 약3~3.5등신의 성인 SD 비율, 둥근 볼·작은 반짝이는 눈·작은 코와 닫힌 입, 짧고 말랑한 손발로 바꾼다.
- 민트 일반형 / 피스타치오색 통통한 대형 / 따뜻한 얼굴과 겨자색 평상복 위 청록 코팅의 구조 대상.
- 외곽선과 명암 덩어리를 단순하게 만들고 반사광과 기포만으로 젤리 느낌을 살린다.
- 움푹 팬 눈·해골 턱·이빨·갈비뼈·힘줄·날카로운 손·근육 덩어리·길게 늘어지는 점액을 제거한다.
- Idle4 / Walk6 / Run6 / Attack6 / Dead6, 종별28포즈,120×120을 유지한다.
- 사냥종 Dead는 말랑한 젤리 웅덩이, 구조 대상 Dead는 점액 이탈 후 살아서 손을 드는 구조 대기다.
- 기존 `../Monsters`와 순덕/오토바이 원본은 보존한다. 새 정본은 이 `Monsters_Cute`에 둔다.

## 인간 구조 대상 전신 코팅 수정

사용자 요청에 따라 기존 v002 파일에서 청록 점액을 머리·양어깨·가슴/배/등·허리/골반·양팔/양손·양다리/무릎/발목/신발까지 이어지는 전신 외피로 늘렸다. 따뜻한 얼굴 일부와 겨자색/남색 의상 패치를 남겨 실제 사람이 안에 있음을 읽히게 한다. 귀여운 표정과 포즈, 120px/28프레임/5동작 구조를 유지한다. Dead는 외피가 점차 벗겨지고 마지막 두 프레임에서 살아 있는 사람이 드러난다. 코팅 없는 몸체 복원 원화는 기존 것을 사용한다.
