# project10 Aseprite 작업 규칙

2026-10-21 · project09 가이드에서 공통 제작·보존·QA 원칙을 가져와 현재 요청에 맞게 적용한다.

## 우선순위와 경로

사용자의 현재 요청, 해당 작업 최신 README·QA, 이 문서, project09 참고 가이드 순서로 확인한다. project09의 활·새총·캐릭터 디자인·17색·300px·1254px·Unity 연결 경로는 과거 작업의 값이며 새 프로젝트의 기본값으로 복사하지 않는다.

사용자가 지정한 `Assets/Artsource`를 편집 원본 루트로 사용한다. 후보는 `Drafts/<작업명>/vNNN/`, 확정본은 추후 `Production/`, 공통 가이드는 `Guides/`에 둔다. 버전 README에 각 후보의 편집 정본 한 개와 대응 PNG를 명시한다. 이전 버전이나 사용자 수정본을 덮어쓰기 전 보존본과 SHA-256을 남긴다.

## 픽셀 제작

- 픽셀 작업은 Aseprite에서 편집 가능한 원본으로 저장한다. 신규 작화인지 기존 픽셀 수정인지 방법을 기록한다.
- 캔버스와 실제 실루엣 크기를 구분한다. 이번 할머니 후보의 캔버스는 64×64, 논리 픽셀은 1px다.
- 제한 팔레트, 정돈한 명암 덩어리, 읽히는 외곽선, 따뜻한 얼굴과 장비 실루엣을 우선한다. 외곽 알파는 0/255, 확대는 정수 배율·최근접을 사용한다.
- 머리·몸·팔·손·장비·효과를 역할에 맞게 분리하고, 팔·장비에 가려진 몸통도 그린다. 총구 효과는 별도 레이어로 끌 수 있게 한다.
- 레이어의 이름·순서·기본 표시·출력 정책, 캔버스·팔레트·발 접점·손잡이·총구 좌표를 README와 메타데이터에 기록한다.

## 저장 후 검수

1. 저장된 `.aseprite`를 다시 읽어 캔버스·프레임·레이어·팔레트·알파와 PNG 픽셀 일치를 검사한다.
2. 검수용 복사본의 실제 visible 상태를 전환해 모든 레이어를 단독 표시하고, 기본 조합에서 하나씩 숨겨 가려진 면과 불필요한 혼입을 확인한다. 재현 스크립트와 결과 이미지를 남긴다.
3. 전체 합성, 실제 64px, 최근접 확대, 밝고 어두운 배경에서 얼굴·의상·발·손–총 접점을 확인한다. 정본의 기본 표시 상태는 복원한다.
4. 파일 규격 검사와 작화 검수의 결과를 따로 기록한다. 미검수·수정 필요를 통과로 쓰지 않는다.
5. 정적 베이스 이미지는 정적 1프레임으로 명시한다. 애니메이션·게임 연결·Unity 실화면 검수는 실제 수행한 경우에만 완료로 기록한다.
