# 컨셉북 확인 기록

2026-10-14. 이번 범위는 기존 아트 소개·합성·첨부이며 원본의 신규 작화 QA는 아니다.

- Notion 기획서 하위의 날짜 포함 페이지 생성 확인.
- 페이지를 다시 읽어 17개 이미지/GIF 첨부, 메인씬 3종, 8개 개별 동작과 2열 배치, Blender 시도, 동물 시트를 확인했다.
- 64×64 소스 동작 프레임: 5 / 8 / 4 / 4 / 4 / 6 / 6 / 4. 저장된 GIF의 프레임 수와 반복 설정을 확인하고 첫·중간 포즈를 눈으로 검사했다.
- 숲 합성은 64프레임, 6.4초 반복. 중간 프레임에서도 UI·헌터·동물의 위치와 겹침을 확인했다. 사슴 발과 여우 귀의 일부 시각적 겹침은 단순 이동 목업에 남아 있다.
- 오두막 합성에서 숨김 참조·64격자 레이어가 섞인 첫 시도를 발견했다. 표시 소품 인덱스만 합성하도록 수정하고 그리드와 원래 숲의 사각 배경 혼입이 제거된 이미지를 다시 확인했다.
- 모든 GIF는 5MiB 미만. 8개 동작의 통합 GIF는 40프레임이다.
- manifest에 기록한 원본 SHA-256을 재검사해 변경 0을 확인했다.
- Unity를 짧게 실행해 실제 화면을 캡처했다. 종료 후 진행 파일과 .bak을 복원했으며 각각 캡처 전 보존본과 해시가 일치했다. 씬·배치·Unity Assets는 변경하지 않았다.
- Notion fetch에서 업로드 URI가 실제 파일 블록으로 전환된 것을 확인했다. 브라우저에서 모든 GIF를 직접 재생한 검수는 포함하지 않는다.

완성되지 않은 원본 동작·3D 형태는 고치지 않고 페이지에 시안으로 표시했다. 원본의 레이어별 신규 QA, 게임 애니메이션 연결, 리깅·최적화는 이번 범위가 아니다.

## ② 오두막 v002 조정

오두막·소품을 1.5배 최근접 확대하고 바닥을 y600으로 내려 단색 잔디(y520부터) 안에 배치했다. 헌터를 왼쪽 전경으로 옮겼고 UI 4개 이미지는 그대로 사용했다. UI 시작 y630과 오두막·헌터가 겹치지 않는 화면을 눈으로 확인했다. 소스 17개의 해시 변경 0을 확인했다. 이전 장면은 scene_02_cabin_concept_v001.png에 보존했다. Notion에서 ② 사진을 교체하고 전체 19개 첨부와 다른 18개 자료의 파일명 보존을 재확인했다.
