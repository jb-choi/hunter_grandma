## 앞으로 참고 자료를 추가할 때

- 원본 URL/작성자·날짜·사용 목적·사용 가능한 범위를 함께 기록한다.
- 외부 게임/이미지는 색·구도·정보 구조 등 참고할 항목을 명시하고 그대로 납품하지 않는다.
- 실제 제작 후보는 해당 AD 폴더 또는 `ArtSource/Drafts`에서 관리한다.
- 사용자 시안의 우측 메뉴/하단 바/접기 구조는 기획에 기록된 요구다. 이번에 해당 시안 원본 파일을 직접 열어 확인한 것으로 쓰지 않는다.
