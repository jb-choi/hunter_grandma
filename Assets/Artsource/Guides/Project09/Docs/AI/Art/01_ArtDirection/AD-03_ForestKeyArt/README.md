# AD-03 · 숲+길+수레 키아트

P0 · 상태: 제작 지시 작성 / 키아트 제작 대기 · 2026-10-11

## 목적과 산출물

큰 숲 안의 작은 사냥꾼과 좌측 캠프가 읽히는 **960×540 키아트 1장**을 제작한다. UI 없는 배경 합성본, 실제 base를 얹은 검수본, 배경/소품의 분리 레이어를 함께 납품한다. 정식 자산 원본 해상도는 키아트에서 픽셀 밀도를 검수한 뒤 결정한다.

현재 위치 참고: [Cycle17 캠프 화면](../../03_References/Baseline_2026-10-10/Cycle17-camp.png). 임시 나무/길/시설의 그림을 완성 아트로 취급하지 않는다.

## 구도와 레이어 지시

| 단계 | 제작 방향 | 분리/검수 |
| --- | --- | --- |
| 하늘·공기 | 밝고 조용한 면 | BG-01, 단독 export |
| 원경 숲 | 저채도·낮은 명암 실루엣 | BG-02, 얼굴보다 대비 낮게 |
| 중경 수관 | 큰 숲의 덩어리와 깊이 | BG-03, 반복 경계 확인 |
| 큰 나무 | 실루엣 3종 시작안, 넓은 잎 덩어리 | BG-04, 캐릭터와 별도 |
| 길/잔디 | 연속 바닥, 발이 놓일 빈 길 | BG-05, 32×32/64×32 타일은 후보 |
| 캠프 | 좌측 수레, 시설 자리와 적재 공간 | PR-03/07/08, 각각 별도 자산 |
| 전경 | 가장자리의 풀/잎, 낮은 밀도 | 행동/얼굴/조준 범위 가림 금지 |

사냥꾼/동물/UI는 배경 원본에 합치지 않는다. 검수용 합성본만 같은 장면에 얹는다. 토끼와 호랑이를 각각 놓아 가장 작은 얼굴과 가장 큰 운반 영역을 확인한다.

## 현재 코드와 맞출 내용

- 현재 ArtSet은 sky/distantForest/middleForest/trail/trees[]와 cart를 받는다. sky는 화면 전체, 원경은 정규화 y .36–.745, 중경은 .22–.43, 길은 .12–.22에 stretch 표시한다. y는 아래쪽 0 기준이며, 실제 합성에서 늘어남을 확인한다.
- 기존 수레 표시 박스는 78×68 참조 단위다. 상단 적재 아이콘 영역을 비워 둔다. 활/화살은 별도 소품이며 배경에 그리지 않는다.
- 하단 ground/deck, 풀·돌·꽃과 수레 앞 테두리는 전용 ArtSet 슬롯이 없다. 해당 레이어 납품과 적용 코드 연결을 별도 상태로 기록한다.
- 시설 표시 박스는 60×72다. 훈제 시설의 불씨는 현재 코드에서 별도로 겹치므로 화구 위치와 일치하는지 확인한다.
- 배경 자산의 해상도와 캐릭터 32×32 격자를 같은 의미로 취급하지 않는다. 길 타일/나무 시작 크기는 실제 표시 픽셀 밀도에 맞춰 확정한다.

## 검수 조건

- [ ] 숲이 크고 사냥꾼이 작은 인상이며 기존 인물 크기를 키워 해결하지 않는다.
- [ ] 3해상도에서 얼굴·발·화살 경로·큰 동물 운반 공간이 읽힌다.
- [ ] 원경/중경/나무의 대비와 빛 방향이 연결된다.
- [ ] 반복 경계와 stretch 왜곡을 확인한다.
- [ ] 캠프와 수레가 겹치지 않고 적재 표시 공간이 남는다.
- [ ] UI를 얹어도 주요 행동이 읽히며 펼침/접힘의 본 화면이 같다.
