# AD-02 · 사냥꾼+6종 크기 비교 시트

P0 · 상태: 제작 지시 작성 / 정식 시트 제작 대기 · 2026-10-11

## 목적과 산출물

기존 base sprite를 같은 바닥에 놓고 작은 사냥꾼, 작은 동물, 큰 동물의 관계를 검수한다. **비교 시트 1장**을 제작하고 높이·발 접점·캔버스/알파 경계 가이드를 함께 표시한다. 신규 캐릭터 디자인을 제안하는 작업으로 확대하지 않는다.

출발 자료는 [Cycle14 비교 화면](../../03_References/Baseline_2026-10-10/Cycle14-size-comparison.png)과 [전체 방향의 비율 표](../ArtDirection.md)다. 기존 QA 화면은 비율 참고이며 정식 AD-02 완성본이 아니다.

## 제작 지시

- 960×540 비교 합성본에서 `hunter, rabbit, boar, deer, magpie, tiger, fox` 순서로 배치한다. 실제 원본 PNG를 사용한다.
- 게임의 `hunterHeight=42`와 종별 설정 배율 `.85 / 1.8 / 2 / .9 / 2.6 / .9`를 출발점으로 한다. 사냥꾼의 보이는 높이를 1.00으로 표기한다.
- 실제 보이는 높이 기준은 토끼 약 .93, 멧돼지 1.73, 사슴 2.01, 까치/여우 .87, 호랑이 2.55다. 원본 셀 크기나 설정 배율과 구별해서 캡션을 붙인다.
- 각 발 접점에 기준선을 표시하고 귀·뿔·꼬리를 포함한 비투명 경계를 표시한다. 그림 자체를 늘리거나 비율을 왜곡하지 않는다.
- 얼굴/모자/귀/꼬리/줄무늬와 손·활 접점을 확대 인셋으로 확인한다. 인셋 확대는 정수 배율+Nearest로 한다.
- 배경색은 차분한 숲/흙 2면 정도로 제한한다. 정식 배경 구도는 AD-03에서 결정한다.
- 토끼 들기와 호랑이 견인은 후속 애니메이션의 추가 비교 항목이다. 이번 정적 시트로 운반 애니메이션 제작 완료를 기록하지 않는다.

## 검수 조건

- [ ] 작은 세 종이 사람보다 살짝 작고 호랑이는 확실히 크다.
- [ ] 640×360 합성본에서 모자·얼굴·활, 종별 귀/뿔/꼬리를 식별한다.
- [ ] 그림의 가로세로 비율과 기존 색/무늬가 유지된다.
- [ ] PNG 전체 캔버스, Unity slice, 비투명 경계가 구분되어 기록된다.
- [ ] 발 접점과 확대/반전 기준이 기록되고 외곽 특징이 잘리지 않는다.
