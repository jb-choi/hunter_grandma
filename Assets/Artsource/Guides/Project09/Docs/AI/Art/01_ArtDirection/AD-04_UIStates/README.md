# AD-04 · UI 펼침/접힘 시안

P0 · 상태: 제작 지시 작성 / 시안 제작 대기 · 2026-10-11

## 목적과 산출물

AD-03의 **동일한 본 화면 위에 펼침/접힘 2장**을 만든다. 우측 세로 메뉴와 하단 관리 바, 접힌 카드/바로가기가 숲과 어울리면서 상태·정보를 읽기 쉽게 정리한다.

## 유지할 구조

- 본 화면의 숲·길·캐릭터·수레 위치와 크기는 두 시안에서 같게 둔다. UI용 여백을 만들기 위해 본 화면을 줄이지 않는다.
- 우측 메뉴 순서는 **창고 → 활 장비 → 동물 도감 → 탐색 지역 → 목표/기록 → 설정**이다.
- 같은 기능의 우측/하단 아이콘은 같은 원본을 쓴다. 메뉴 이름과 선택 프레임을 함께 표시한다.
- 하단은 골드·창고·목표 등 관리 정보와 사냥 제어를 담는다. 글자/수치/아이콘과 프레임은 분리한다.
- 접힘 상태에서도 열기, 주요 정보, 필요한 관리 접근과 사냥 제어의 판독성을 확인한다.

## 스킨 지시

나무 외곽과 종이/크림 내부를 기본으로 한다. 차분한 보라는 보조 버튼, 금색은 선택/성과 포인트의 시작안이다. 보라 HEX는 실제 색 비교 후 `PaletteAudit.md`에 후보 또는 채택 상태로 기록한다.

일반 버튼의 기본·가리킴·눌림·비활성과 선택 상태를 공통 프레임으로 제시한다. 비활성은 색 저하만으로 처리하지 않고 기능이 멈췄음을 읽게 한다. 메뉴 접기/펼치기 화살표 방향, 닫기 X, pause/play를 서로 혼동하지 않게 한다.

메뉴 아이콘은 32×32 원본, 현재 우측 표시 24×24에서 검수한다. 글자는 이미지에 넣지 않고 UI Text로 남긴다. 가이드 시트 캡션은 문서용 PNG에만 넣을 수 있다.

## 적용 범위

`HuntArtSet.menuIcons[]`는 현재 연결 가능하다. 메뉴 배경·하단 바·버튼 프레임·상태 스킨은 현재 코드 도형/색으로 생성되며 전용 아트 슬롯이 없다. **시안 제작 → 분리 자산 제작 → 스킨 연결 → 실화면 검수**를 각각 기록한다.

## 검수 조건

- [ ] 펼침/접힘의 본 화면 기준점이 동일하다.
- [ ] 640×360에서 6개 메뉴를 그림과 이름으로 구분한다.
- [ ] 주요 글자 12px 이상 기준에서 문구·수치·버튼이 잘리지 않는다.
- [ ] 같은 기능의 우측/하단 그림이 일관된다.
- [ ] 버튼 상태가 색 외의 형태/위치/마크로도 읽힌다.
- [ ] 960×540 / 1280×720에서 프레임 늘어남과 공간 낭비를 확인한다.
