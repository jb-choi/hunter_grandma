# AD-05 · 공통 관리 패널 시안

P0 · 상태: 제작 지시 작성 / 시안 제작 대기 · 2026-10-11

## 목적과 산출물

창고·장비·도감·지역·기록·설정에 재사용할 **공통 관리 패널 시안 1장**을 만든다. 대표 패널에 제목/닫기/내용/스크롤/하단 동작을 보여 주고, 같은 시트의 작은 인셋으로 카드·선택·비활성 상태를 제시한다.

현재 정보량 참고: [Cycle18 도감 패널](../../03_References/Baseline_2026-10-10/Cycle18-menu.png). 기존 패널의 기능을 유지하면서 새 재질과 프레임을 설계한다.

## 공통 구조

| 부위 | 제작 규칙 |
| --- | --- |
| 외곽/모서리 | 나무 재질, 모서리와 변 두께 고정 |
| 내부 | 크림/종이 면, 글자 뒤에 복잡한 무늬 금지 |
| 제목/닫기 | 제목과 X 위치 일관, 누를 영역은 작은 장식과 구별 |
| 본문/카드 | 종/상품 그림, 이름, 수치, 상태의 정보 순서 유지 |
| 스크롤 | 트랙/손잡이 분리, 목록 마지막 항목까지 접근 |
| 하단 동작 | 자동 생산/레시피 선택/강화/수령/저장 등 주요 동작과 비활성 이유를 구분 |

프레임은 9-slice 또는 모서리·변·중앙 분리 납품을 계획한다. 선택한 방식의 border 픽셀 수와 최소 표시 크기를 기록한다. 여러 크기에 맞추려고 모서리를 늘리거나 외곽선을 흐리게 만들지 않는다.

텍스트·가격·진행값은 PNG에 넣지 않는다. 도감은 기존 6종 base를 썸네일로 시작하고 전용 초상화는 후속 작업으로 남긴다. 기록의 긴 목록, 목표 카드의 완료/수령 상태, 레시피 선택과 생산 상태를 공통 컴포넌트로 표현한다.

## 기능별 대조

- 창고: 재료 재고·진행 중 상품·다음 선택 레시피·판매 누계·재료 0 대기 상태를 구분한다. 동작은 자동 생산 정지/재개와 다음 레시피 선택이며 판매는 생산 완료 후 자동 처리된다.
- 장비: 활 강화와 비용·불가 상태가 명확히 읽혀야 한다.
- 도감: 탐색 강화와 비용·불가 상태를 표시한다. 큰 호랑이 썸네일과 긴 사슴 뿔이 슬롯 밖으로 잘리지 않아야 한다.
- 지역: 현재 작은 숲, 시설 강화와 비용·불가 상태를 표시하고 후속 지역 표현과 구분한다. 시안만으로 지역 해금 구현 완료를 기록하지 않는다.
- 기록/목표: 진행·보상 가능·수령 완료를 구분하고 마지막 목록까지 스크롤할 수 있어야 한다.
- 설정: 토글·저장·닫기·선택 상태가 공통 버튼과 일관되어야 한다.

## 검수 조건과 적용

- [ ] 6개 패널에 같은 프레임/여백/제목/닫기 규칙을 적용할 수 있다.
- [ ] 640×360에서 본문과 하단 동작이 잘리지 않고 스크롤 손잡이가 읽힌다.
- [ ] 3해상도에서 모서리/외곽선이 변형되지 않는다.
- [ ] 선택·눌림·비활성·완료가 구분된다.
- [ ] 그림/텍스트/프레임의 분리와 9-slice 경계 값이 기록된다.

현재 공통 패널 스킨 슬롯은 없다. 자산 납품 뒤 `PixelUi.Frame`과 HUD/카드 생성부의 연결 작업 및 6패널 실화면 검수가 필요하다.
