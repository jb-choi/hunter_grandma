# 픽셀 면·경계 정리 기준

v0.1 · 2026-10-11 · Hunter_300 v006부터 적용

**기존 캐릭터의 디자인·포즈·인상을 유지하면서 각 재질의 면과 경계를 직접 정리한다.** 작은 색 조각을 합치는 작업과 선의 모양을 고치는 작업을 함께 진행한다. 색 수·반투명 검사만으로 작화 정리 완료를 판단하지 않는다.

## 1. 네 가지 작업 기록

공통 원칙은 이 문서에서 관리하고, 실제 기준 예시·부위 마스크·수정 기록·검수 이미지는 각 버전 폴더에 보관한다. v006의 작업 루트는 [Hunter_300/v006](../../../../ArtSource/Try/Hunter_300/v006/README.md)이다.

| 요소 | 버전별 저장 위치 | 기록할 내용 |
| --- | --- | --- |
| 정리 기준 예시 | `Reference/cleanup_reference.aseprite` | 같은 영역의 수정 전후, 제거한 띠·돌출, 남긴 형태·명암 |
| 부위별 면 구분 | `Clips/HU-01_idle/Masks/material_regions.aseprite` | 프레임별 부위 범위, 보존 디테일, 수정 가능한 경계 범위 |
| 경계 수정 규칙과 실제 처리 | 공통 `PixelCleanupGuide.md`, 버전 `Prompts/` 및 `QA/` | 기준을 적용한 방법, 예외, 실제 바뀐 픽셀·범위 |
| 전신 시각 검수 | `QA/visual_review.md` 및 연결된 전후 이미지 | 모든 부위·프레임의 판정, 원래 표시 크기와 재생 확인, 남은 문제 |

기준 예시와 마스크는 실제 Aseprite 편집 파일로 만든다. 경로만 적거나 이미지에 색 수 검사를 한 것으로 이 네 요소를 대체하지 않는다. 안내·마스크 레이어는 최종 캐릭터 PNG와 시트 내보내기에서 제외한다.

## 2. 기준 예시를 먼저 만든다

한 프레임의 깃털과 모자를 먼저 정리한다. 같은 위치의 수정 전후를 비교할 수 있도록 원본과 수정본을 레이어 또는 명확한 프레임 이름으로 구분한다. 예시에는 다음 판단을 함께 기록한다.

- 한 면 안에서 대표색으로 합친 작은 색 조각과 가는 띠.
- 선 두께를 흐트러뜨리는 작은 돌출·패임과 그 수정 방향.
- 형태를 설명하므로 남긴 깃털 끝, 모자 접힘, 장식과 의도한 명암 경계.
- 곡선·사선의 큰 흐름을 따라 정돈한 계단 진행.

300×300은 캔버스 크기다. 표현상의 도트 크기·외곽 두께는 실제 예시를 보고 기록한다. 별도 기준이 확정되기 전에는 전체 그림을 일정한 저해상도 격자로 다시 그리거나 모든 계단 길이를 같게 만들지 않는다. 확대할 때 나타나는 모든 계단을 오류로 취급하지 않는다.

## 3. 부위를 구분한 뒤 픽셀을 판단한다

색 값만으로 재질을 판단하지 않는다. 같은 갈색도 머리카락에서는 정상 음영이고 깃털 가장자리에서는 잔색일 수 있다. 마스크는 각 프레임의 위치와 형태에 맞춰 작성한다.

기본 검수 부위는 깃털, 모자 본체·챙·띠, 머리카락, 얼굴·눈·귀, 목·스카프, 몸통, 양팔·손, 벨트·버클, 양다리·신발, 활·활줄, 화살·화살통이다. 특정 그림에 없는 부위는 검수 표에서 해당 없음으로 적는다. 서로 맞닿는 면의 경계도 검사 대상에 포함한다.

마스크 또는 동반 설명에 다음 세 범위를 구분한다.

| 범위 | 처리 기준 |
| --- | --- |
| 재질 면 | 부위의 기본색·명암색으로 합칠 수 있는 영역 |
| 수정 가능한 경계 | 잔색 띠·돌출·패임을 없애기 위해 여러 픽셀을 함께 고칠 수 있는 영역 |
| 보존 디테일 | 눈의 형태, 귀 구멍·음영, 머리카락 결, 버클 구멍, 활줄 등 기능과 형태를 설명하는 부분 |

보존은 의미와 형태를 유지한다는 뜻이다. 원본의 검정 픽셀과 투명 마스크 전체를 일괄 고정하지 않는다. 경계의 잡색과 잘못된 턱까지 보호하지 않도록 보존 범위를 구체적으로 정한다.

## 4. 경계의 모양을 직접 고친다

고립된 픽셀뿐 아니라 면에 붙어 있는 좁은 띠, 여러 픽셀로 이어진 돌출, 짧은 지그재그도 검토한다. 이웃 다수결이나 색상 양자화는 수정 후보를 찾는 보조 수단으로만 사용한다. 기준 예시와 재질 구분을 확인하고 경계를 따라 수정한다.

1. 각 면의 기본색·그림자·하이라이트를 확인한다. 형태 설명에 기여하지 않는 잔색을 해당 면의 대표색으로 합친다.
2. 외곽과 내부 명암 경계를 따라 불필요한 가는 띠와 작은 턱을 찾는다. 기존 검정 윤곽·투명 영역에 걸친 부분도 수정할 수 있다.
3. 곡선·사선의 방향과 주변 선 두께에 맞게 여러 픽셀을 함께 고친다. 큰 형태를 유지하면서 작은 계단이 갑자기 꺾이거나 선이 국소적으로 두꺼워지는 부분을 정돈한다.
4. 보존 디테일과 큰 명암 면을 다시 확인한다. 작은 디테일을 모두 대표색으로 지우거나 실제 직각 모서리를 기계적으로 둥글게 만들지 않는다.
5. 한 프레임의 기준을 다른 프레임에도 적용한다. 좌표를 그대로 복사하지 않고 움직인 부위의 위치·접점·명암을 확인한다.

새 이미지 재생성, 블러, 안티앨리어싱, 디더링, 색 평균 보간을 사용하지 않는다. 기존 Aseprite 픽셀을 직접 수정하고 기존 팔레트를 우선 사용한다. 확대 비교 이미지는 최근접 보간으로 만든다.

## 5. 전신·전 프레임 검수

레이어별 단독 표시와 한 레이어씩 숨긴 상태의 검수는 [범용 아트워크 가이드 §8](ArtworkGuide.md#8-공통-qa-순서와-필수-확인)을 함께 적용한다. 저장 파일의 실제 visible 상태를 전환해 모든 레이어·프레임의 혼입·경계·숨은 면을 확인한 뒤 전체 합성을 평가한다. 검수 후 정본의 기본 표시 상태를 복원한다.

작업 전 원본의 보존본과 해시를 남긴다. 작업 후 편집 파일을 다시 열어 내보낸 PNG와 같은 픽셀인지 확인한다. 캔버스, 프레임 수, 태그, duration, 팔레트, 알파 상태와 실제 변경 수를 기록한다. 원본과의 픽셀 차이는 수정 위치를 확인하는 자료이며, 변경 수가 많거나 적다는 이유만으로 품질을 판정하지 않는다.

`QA/visual_review.md`에는 최소한 다음 열을 둔다.

| 부위 / 프레임 | 전후 이미지 | 확인한 경계·디테일 | 판정 | 남은 문제 |
| --- | --- | --- | --- | --- |
| 예: 깃털 / 1 | 해당 영역의 같은 배율 비교 링크 | 색 띠, 외곽 두께, 깃털 끝 | 정리됨 / 추가 수정 필요 / 미검수 | 구체적인 위치와 이유 |

모든 부위를 두 프레임 이상이면 각 프레임에서 확인한다. 확대 검수에서는 띠·돌출·패임·선 두께·계단 진행을, 원래 표시 크기에서는 인상·형태·디테일 가독성을 확인한다. 재생 검수에서는 프레임 사이에 경계·명암·장비가 불필요하게 흔들리는지 확인한다. 작은 게임 표시 크기는 해당 비교 재생기의 실제 설정과 함께 기록한다.

기준 예시의 개선, 전신 검수, 파일 무결성 검수는 각각 구분해 보고한다. 검수하지 않은 부위를 통과로 적지 않는다. 남은 문제는 전후 이미지와 함께 명시하고, 일부 부위만 정리된 상태를 전신 정리 완료로 보고하지 않는다. 실험 결과가 아직 거칠면 `추가 수정 필요`로 남겨 다음 버전의 수정 범위를 정한다.

## 6. 확인 순서

작업 전에는 이 가이드 → 해당 버전 README → 기준 예시 → 부위 마스크를 확인한다. 작업 후에는 파일 검수 → 전신 확대 비교 → 원래 표시 크기 → 애니메이션 재생 → `visual_review.md` 기록 순서로 확인한다. 다음 버전은 직전 검수의 남은 문제를 읽고 시작한다.
