# ArtSource 작업 지침

이 폴더와 하위 폴더의 편집 원본·시안·비교 실험 작업에 적용한다. 사용자가 이 대화에서 지정한 범위·방법·보존 요구가 우선한다. Unity 자산 적용은 별도 요청과 기존 참조 확인에 따라 진행한다.

## 작업 전 확인

- [범용 아트워크 제작·QA 가이드](../Docs/AI/Art/02_Production/ArtworkGuide.md)를 확인한다. 최신 입력 선택, 레이어 역할·표시 정책, 단독/숨김·전체·실제 크기 검수와 기록 양식을 공통으로 적용한다.
- [저장·납품 규칙](../Docs/AI/Art/02_Production/ProductionGuide.md)을 읽고, 해당 작업의 README에서 편집 정본·입력 원본·현재 상태를 확인한다.
- 기존 캐릭터의 색·면·경계를 정리할 때는 [픽셀 정리 가이드](../Docs/AI/Art/02_Production/PixelCleanupGuide.md)를 적용한다.
- 해당 버전의 `Reference/cleanup_reference.aseprite`, 클립의 `Masks/material_regions.aseprite`, 직전 버전의 `QA/visual_review.md`를 확인한다. 아직 없는 경우 현재 버전에 기준 예시·부위 마스크를 만들어 실제 수정에 사용한다.
- 이전 버전 원본을 덮어쓰지 않는다. 사용한 원본을 현재 버전 `Source/`에 보존하고 해시를 기록한다. 새 실험은 `Try/<실험명>/vNNN/` 체계를 따른다.

## 픽셀 정리 방법

- 디자인·포즈·캐릭터 인상을 유지하면서 재질별 면과 경계를 기존 Aseprite 픽셀에서 직접 수정한다. 사용자가 금지한 이미지 재생성·블러·안티앨리어싱·디더링을 사용하지 않는다.
- 색 수 제한과 이웃 픽셀 필터만으로 정리 완료를 판단하지 않는다. 면에 붙은 얇은 띠, 여러 픽셀 돌출, 선 두께와 계단 진행을 영역 단위로 검토하고 수정한다.
- 눈·귀·머리카락·버클·활줄 등 형태를 설명하는 디테일은 의미와 형태를 보존한다. 검정 윤곽·투명 영역 전체를 자동 보호해 잔색과 돌출까지 남기지 않는다.
- 캔버스 크기를 표현상의 도트 격자로 간주하지 않는다. 기준 예시와 사용자 요구 없이 일정한 저해상도 격자나 획일적인 계단 길이를 강제하지 않는다.
- 마스크·지시·비교 레이어는 캐릭터 export에서 제외한다. 실제 결과와 기준 예시·마스크의 대응을 README에 설명한다.

## 검수와 보고

- 편집 파일을 다시 읽어 PNG와의 일치, 프레임·duration·태그·팔레트·알파 상태, 원본 보존 여부를 확인한다.
- 저장된 편집 파일의 실제 visible 상태를 전환해 모든 레이어·프레임을 한 레이어만 표시한 상태로 확인하고, 기본 export 조합에서 한 레이어씩 숨겨 가려진 면·혼입·누락을 확인한다. 숨긴 보존·참조·가이드와 의도한 빈 레이어도 역할별로 기록하고, 검수 후 정본의 기본 표시 상태를 복원한다. 전체 합성이나 레이어 PNG 일치만으로 단독 작화 검수를 대체하지 않는다.
- 머리부터 신발·장비까지 모든 부위를 전 프레임에서 확대 비교하고, 원래 표시 크기와 애니메이션 재생도 확인한다.
- `QA/visual_review.md`에 부위별 이미지 링크, 판정, 남은 문제를 기록한다. 미검수와 추가 수정 필요를 통과로 기록하지 않는다.
- 수치 검수 통과와 작화 검수 결과를 구분한다. 일부 부위만 개선된 경우 전체 경계 정리 완료로 보고하지 않는다.
- 결과 전달에는 편집 원본과 전후 비교 또는 재생기, 검수 기록 경로를 제시하고 실제 해결 범위와 남은 문제를 짧게 설명한다.
