# 기존 idle 생성 프롬프트 보관

[HU-01 idle 프롬프트](HU-01_idle.md)는 `Hunter_1254/v001`에서 사용한 문서를 그대로 복사한 출처 기록이다. 기준 그림은 [hunter_base_1254.png](../Reference/hunter_base_1254.png)이며, 기존 생성은 내장 imagegen 편집 모드·투명 배경으로 진행했다.

**이번 Hunter_300 시험에서는 imagegen을 새로 호출하지 않았다.** 기존 idle 편집 파일을 Aseprite의 최근접 이웃 방식으로 300×300으로 축소했다. 이 프롬프트를 사용해 300 원화를 새로 만든 것으로 해석하지 않는다.
