# HU-01 / idle — 300×300 비교 시험

기존 1254 idle을 Aseprite의 최근접 이웃 방식으로 축소했다. 개별 프레임과 편집 파일의 캔버스는 **300×300**이며, 투명 여백을 제외한 캐릭터 높이는 두 프레임 모두 234px다. 시트는 가로 2장으로 배치한 600×300이다.

현재 포즈·색·장비 표현을 유지한 해상도 비교본이다. 새 원화 생성이나 안티앨리어싱·색 경계 보정은 하지 않았다. 모자·얼굴의 프레임 간 형태 변화와 원본의 중간색은 남아 있다.

키포즈를 수정할 파일은 이 폴더의 `idle.aseprite`다. [Source](Source/README.md)의 1254 보관본과 생성 시트는 축소 전 출처를 확인하는 자료다. PNG·GIF·시트는 현재 편집 파일의 출력물이며, 이후 키포즈를 바꾸면 다시 내보내야 한다.

몸과 장비가 함께 들어 있는 시험 합성본이며 Unity에는 적용하지 않았다.
