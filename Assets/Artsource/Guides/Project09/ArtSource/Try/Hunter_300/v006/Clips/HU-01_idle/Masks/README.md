# 부위별 작업 마스크

[material_regions.aseprite](material_regions.aseprite)는 두 프레임의 작업 부위를 구분하는 별도 Aseprite 파일이다. [regions.json](regions.json)에 각 식별 색과 부위의 대응을 기록한다. 마스크는 그림의 새 색이나 명암을 지정하는 파일이 아니다.

| 레이어 | 역할 | 기본 표시 |
|---|---|---|
| `MaterialRegions` | 위치·재질에 따라 나눈 13개 부위 | 표시 |
| `PreservedDetails` | 눈·귀 디테일·버클·활줄의 지정 보존 범위 | 표시 |
| `EditableBoundaries` | 직접 정리 대상으로 확인할 경계 범위 | 숨김 |

마스크에는 별도 팔레트 16칸을 사용한다. 0은 투명, 1~13은 재질 부위, 14는 보존 디테일, 15는 수정 경계의 식별 색이다. 실제 캐릭터의 17칸 팔레트와 의미가 다르므로 마스크의 색 인덱스를 그림에 대입하지 않는다.

부위 1~13은 깃털, 모자 본체·챙, 모자 띠, 머리카락, 얼굴·귀·목, 스카프·몸통, 가죽·끈·장갑, 손, 버클, 다리, 신발, 활·활줄, 화살·화살통 순서다. 마스크는 색 값만으로 분리하지 않고 위치와 재질의 의미를 함께 사용했다. 프레임별 지정 보존 사각형과 발끝 하이라이트 수정 범위도 `regions.json`에 기록한다.

같은 갈색·녹색을 사용하더라도 깃털, 머리카락, 가죽, 모자 등 부위의 의미에 맞춰 정리한다. 경계 픽셀이 다른 부위에 속한 잔색인지, 의도한 재질 음영인지 판단할 때 이 마스크와 [기준 예시](../../../Reference/cleanup_reference.aseprite)를 함께 확인한다.

마스크의 식별 색은 [실제 그림](../idle.aseprite)과 PNG·시트·GIF 내보내기에서 제외한다. 부위의 형상이나 위치를 수정한 경우 마스크도 해당 프레임에 맞춰 확인한다. 경계 전체를 고정하는 보호 마스크로 취급하지 않는다. 보호할 형태 디테일과 수정할 경계는 [정리 명세](../../../Prompts/cleanup_spec.md)에 따른다.
