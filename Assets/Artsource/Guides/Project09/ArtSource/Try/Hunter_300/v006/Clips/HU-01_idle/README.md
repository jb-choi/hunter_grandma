# HU-01 / idle — v006 면·경계 정리

300×300 Indexed · 태그 `idle` · 2프레임 · 각 500ms · 1초 반복

[편집 파일](idle.aseprite) · [1번 PNG](Frames/idle_01.png) / [2번 PNG](Frames/idle_02.png) · [시트](Export/idle_sheet.png) / [메타](Export/idle.json) · [시험 전체 안내](../../README.md)

입력은 [v005 보관본](Source/idle_300_v005.aseprite)이다. 깃털·모자의 기준 예시와 [부위별 마스크](Masks/README.md)를 사용해 전신의 작은 색 조각, 가는 띠, 불필요한 경계 돌출·패임을 정리한다. 전체 디자인·포즈·캐릭터 인상과 형태를 설명하는 디테일을 유지하되, 경계 주변 여러 픽셀은 함께 수정할 수 있다.

기존 불투명 16색과 투명 1칸을 사용하며 두 프레임 모두 실제 불투명 16색, 반투명 픽셀 0개다. 마스크의 식별 색은 편집 파일과 내보내기에 섞지 않는다. 새 이미지 생성, 블러, 안티앨리어싱, 디더링은 사용하지 않았다.

13개 부위의 위치·재질 범위 안에서 색 면의 3×3 열기·닫기와 가까운 허용 색 면으로 합치는 처리를 적용했다. 이후 보수적인 모서리 정리와 발끝 하이라이트·허리 경계의 개별 수정을 진행했다. 모든 픽셀을 일정한 격자에 맞추는 방식은 채택하지 않았다. [수정 스크립트](../../QA/cleanup_v6.lua) · [수정 위치 기록](../../QA/pixel_edits.json)

변경 픽셀은 1번 694개, 2번 748개다. 투명/불투명 경계 변경 위치는 32개와 51개, 검정색 마스크 변경 위치는 346개와 376개다. 지정 보존 디테일의 불일치는 모두 0개다. 눈·귀 디테일·버클·활줄의 보호 범위는 [부위 정의](Masks/regions.json)에 기록했다. [파일 검수](../../QA/file_validation.json) · [편집 파일 재검수](../../QA/native_validation.json)

독립 재검수에서 편집 파일과 PNG의 픽셀 불일치는 두 프레임 모두 0개이며, 마스크·기준 예시가 원본과 결과에 대응함을 확인했다. 원본 보관본의 바이트 일치와 GIF 2프레임·각 500ms도 통과했다. 수치 검수와 별도로 전신 11개 영역의 두 프레임을 시각 검수했다.

확인 순서는 [기준 예시](../../Reference/cleanup_reference.aseprite) → [정리 명세](../../Prompts/cleanup_spec.md) → [전신 시각 검수](../../QA/visual_review.md)다. 두 프레임 각각의 부위별 확대와 원래 표시 크기를 확인하고, 반복 재생에서 형태·색 경계가 불필요하게 흔들리는지도 확인한다. 완료 여부와 남은 문제는 시각 검수 기록에 따른다.

[11개 부위별 비교](../../Previews/review.html)는 왼쪽 v005/오른쪽 v006, 위쪽 1번/아래쪽 2번 프레임이다. [GIF](../../Previews/idle.gif)와 [비교 재생기](../../Previews/index.html)에서 두 프레임을 반복 확인한다. 기존 생성본의 프레임별 형태·포즈 차이는 남아 있으며 새 애니메이션으로 다시 그리지 않았다.

실제 수정은 이 폴더의 `idle.aseprite`에 진행한다. `Source`는 비교·출처 보관용, `Masks`는 작업 영역 정의용이다. 수정 후 PNG·시트·미리보기도 다시 내보낸다. 이 버전은 Unity 미적용 시험본이다.
