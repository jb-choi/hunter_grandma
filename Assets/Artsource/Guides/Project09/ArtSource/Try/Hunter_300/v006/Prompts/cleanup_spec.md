# v006 면·경계 정리 명세

## 사용자 지시

사용자는 전체 디자인·포즈·캐릭터 인상을 유지하면서 같은 면 안의 작은 색 조각·가는 띠·고립된 픽셀을 대표색으로 합치고, 불필요한 경계 돌출·패임을 정리하도록 요청했다. 눈·귀 구멍·머리카락처럼 형태를 설명하는 디테일과 의도한 명암은 유지한다. 이미지 재생성 없이 기존 Aseprite 픽셀을 직접 수정하고 블러·안티앨리어싱·디더링을 사용하지 않는다.

v005에서 눈과 일부 국소 경계만 정리된 뒤에도 깃털·모자 등 다른 영역의 가는 띠와 작은 돌출이 남았다. 사용자는 정리 기준 예시, 부위별 면 구분, 경계 수정 규칙, 전신 시각 검수의 네 요소를 갖춘 v006 시험을 요청했다.

## 입력과 출력

입력은 [v005 보관본](../Clips/HU-01_idle/Source/idle_300_v005.aseprite), 출력은 [v006 idle.aseprite](../Clips/HU-01_idle/idle.aseprite)다. 300×300 Indexed 캔버스, 2프레임, 각 500ms, `idle` 태그와 기존 팔레트 17칸을 작업 기준으로 유지한다. 새 색과 반투명 픽셀은 만들지 않는다.

## 정리 방식

1. [깃털·모자 기준 예시](../Reference/cleanup_reference.aseprite)에서 남길 형태, 의도한 명암, 없앨 작은 턱과 띠를 확인한다.
2. [부위별 마스크](../Clips/HU-01_idle/Masks/material_regions.aseprite)와 [부위 정의](../Clips/HU-01_idle/Masks/regions.json)를 사용해 같은 색의 서로 다른 재질을 구분한다.
3. 부위별 대표 면과 경계를 함께 다듬는다. 고립된 픽셀뿐 아니라 면에 붙은 얇은 색 띠, 여러 픽셀로 이어진 돌출, 갑자기 가늘어지거나 두꺼워진 윤곽도 확인한다.
4. 두 프레임의 전신을 부위별로 확대하고, 원래 표시 크기와 반복 재생에서 다시 확인한다. 실제 판정은 [visual_review.md](../QA/visual_review.md)에 기록한다.

경계 수정은 원본 검정색과 투명 영역까지 포함할 수 있다. 디자인·포즈 유지가 모든 경계 픽셀의 보존을 뜻하지는 않는다. 선 두께와 계단 진행은 부위의 방향·형태에 맞게 조절하며 모든 계단의 길이를 같게 만들지 않는다. 300px 캔버스 전체를 일정한 저해상도 도트 격자로 재작성하지 않는다.

눈, 귀의 형태, 머리카락의 의미 있는 끝, 깃털의 모양, 손과 장비의 구분, 버클, 활과 활줄 등 형태 디테일은 수정 전후로 따로 확인한다. 큰 명암 면은 유지하고, 같은 면 안의 불필요한 잔색은 그 면의 대표색에 합친다. 재질의 경계와 의도한 명암을 단순히 주변 다수색으로 덮지 않는다.

공통 기준은 [PixelCleanupGuide.md](../../../../../Docs/AI/Art/02_Production/PixelCleanupGuide.md)를 따른다. 해당 기준과 이번 파일의 예시·마스크가 맞지 않는 부분은 시각 검수 기록에 남긴다.

## 실제 적용 방법

[cleanup_v6.lua](../QA/cleanup_v6.lua)에서 13개 부위를 위치와 재질에 따라 구분한 뒤 각 색 면에 3×3 정사각형 열기·닫기를 적용했다. 이를 통해 좁은 돌출과 패임의 후보를 정리하고, 주변에서 해당 부위에 허용하는 가까운 색 면으로 합쳤다. RGB 평균이나 색 보간은 사용하지 않았다.

눈·귀 디테일·버클·활줄의 지정 범위를 별도 보호했다. 깃털의 잘못된 재질색, 손의 녹색 잔색, 활에 섞인 머리카락색 등의 명시적 재질 수정도 적용했다. 이후 보수적인 모서리 정리 두 차례와 프레임별 발끝 하이라이트 사각형 네 곳, 허리 경계의 개별 수정을 진행했다. 정확한 보호·수정 범위는 [regions.json](../Clips/HU-01_idle/Masks/regions.json), 모든 변경 위치·이유는 [pixel_edits.json](../QA/pixel_edits.json)에 기록한다.

원본의 큰 4~5px 색 블록 흐름을 유지하고 전역 격자 정렬은 채택하지 않았다. `QA/Candidates/`의 3·4·5px 후보는 미채택 비교용이다. 기준 예시는 두 프레임의 `Before_v005` 숨김 레이어와 `After_v006` 표시 레이어로 보관한다. 마스크는 `MaterialRegions`, `PreservedDetails`, `EditableBoundaries` 세 레이어로 구분하며 식별 팔레트는 실제 그림에 사용하지 않는다.

[파일 검수 기록](../QA/file_validation.json)의 변경 수치는 1번 694픽셀, 2번 748픽셀, 총 1,442픽셀이다. 투명/불투명 경계 변경 위치는 32개와 51개, 검정색 마스크 변경 위치는 346개와 376개다. 지정 보호 디테일의 불일치는 두 프레임 모두 0개이며 불투명 16색, 반투명 0개다. 원본·출력의 검정 마스크나 실루엣이 완전히 같다는 기준은 적용하지 않는다.

원본 생성본의 두 프레임 사이 형태·포즈 차이는 남아 있다. 이번 작업은 새 키포즈나 애니메이션을 다시 그리는 작업이 아니다.

## 검수 기준

파일 검수에서는 캔버스·팔레트·프레임·타이밍·반투명 여부와 내보낸 PNG의 일치를 확인한다. 이 수치가 통과해도 전신 경계 정리가 완료된 것으로 판단하지 않는다.

시각 검수에서는 각 프레임의 모든 부위를 확인해 잔색 띠, 작은 턱, 윤곽 두께, 의도한 디테일·명암, 전체 인상과 반복 재생 결과를 기록한다. 미확인 부위와 남은 문제를 명시하고 전체 부위 판정이 끝나기 전에는 전체 정리 완료로 기록하지 않는다.

[부위별 비교 재생기](../Previews/review.html)는 11개 영역의 같은 위치를 두 프레임 모두 비교한다. 각 이미지의 왼쪽은 v005, 오른쪽은 v006이며 위쪽은 1번, 아래쪽은 2번 프레임이다. 모든 확대 이미지는 최근접으로 생성했다. [편집 파일 재검수](../QA/native_validation.json), [출처 해시](../QA/source_hash.json), [재생기 검수](../QA/browser_validation.json)도 함께 확인한다.

저장된 편집 파일·마스크·기준 예시·PNG·GIF를 독립적으로 다시 읽은 재검수는 통과했다. 두 프레임의 PNG 불일치, 지정 보호 디테일·마스크 불일치, 기준 예시의 수정 전후 불일치는 모두 0개다. 원본 보관본의 바이트 일치와 기존 팔레트·태그·프레임·타이밍도 확인했다. 전신 작화 판정과 기존 포즈 차이 등 남은 범위는 `visual_review.md`에 별도로 기록했다.
