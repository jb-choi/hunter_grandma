# 수정 전 v005 보관본

[idle_300_v005.aseprite](idle_300_v005.aseprite)는 v006 작업 입력인 [v005 편집 파일](../../../../v005/Clips/HU-01_idle/idle.aseprite)의 보관본이다. 원본의 픽셀·팔레트·프레임·타이밍을 비교하기 위해 보관하며 이 파일에는 v006 수정을 진행하지 않는다.

v006 작업 결과는 [상위 편집 파일](../idle.aseprite)에 저장한다. 원본 보존 여부는 [출처 해시](../../../QA/source_hash.json), 변경 수치는 [파일 검수](../../../QA/file_validation.json)에서 확인하고, 정리 품질은 [전신 시각 검수](../../../QA/visual_review.md)에서 확인한다.

원본은 300×300 Indexed, 불투명 16색과 투명 1칸, 2프레임·각 500ms의 시험 생성본이다. 프레임 사이에 기존부터 있던 형태·포즈 차이는 이번 픽셀 경계 정리로 새로 그리지 않았다.
