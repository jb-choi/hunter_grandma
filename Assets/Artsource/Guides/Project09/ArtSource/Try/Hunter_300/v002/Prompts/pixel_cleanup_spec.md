# idle v002 픽셀 색 정리 지시·실행 기록

사용자 요청: v001 `idle.aseprite`의 흐릿한 색 영역을 픽셀 아트답게 정리하고 많은 색을 줄인다.

새 imagegen 생성 없이 Aseprite의 네이티브 이미지·팔레트 API로 기존 300×300 두 프레임을 수정했다. v001은 보존하며 [보관 원본](../Clips/HU-01_idle/Source/idle_300_v001.aseprite)을 입력으로 사용한다.

- 300×300 캔버스, 두 포즈, idle 태그와 각 500ms 타이밍을 유지한다.
- 모자/튜닉의 초록, 크림 피부/깃털, 금색 머리, 갈색 장비, 어두운 외곽선이 구별되도록 공통 26색을 선정한다. 투명 인덱스 0을 더한 27칸 Indexed 팔레트를 사용한다.
- 생성 원본의 미세한 색 변화는 CIELAB에서 가까운 고정 팔레트 색으로 합친다. 디더링과 새 중간색 보간은 적용하지 않는다.
- 알파 128 미만은 투명, 나머지는 완전 불투명으로 정리한다. 원본의 얇은 반투명 가장자리는 소폭 줄어들 수 있으므로 눈·활줄·깃털·실루엣을 검토한다.
- 녹색/머리카락 면 내부에서 같은 색의 상하좌우 이웃이 없고, 주변 3개 이상이 같은 재료의 한 색인 고립 잔색만 한 번 정리한다. Lab 거리 20 이내로 제한한다. 투명 경계, 외곽선, 피부/눈/볼, 가죽/활/끈은 이 단계에서 제외한다.

실제 결과는 두 프레임 모두 26색, 반투명 픽셀 0개다. 낮은 알파 257/268픽셀을 제거했고, 내부 잔색 22/28픽셀을 정리했다. 원래 234px 보이는 높이와 바닥 위치는 유지한다.
