# idle 색 정리 전 원본 보관

- [idle_300_v001.aseprite](idle_300_v001.aseprite): `Hunter_300/v001/Clips/HU-01_idle/idle.aseprite`의 보관본. 이번 색 정리에 직접 사용한 300×300 편집 원본이다.
- [idle_1254.aseprite](idle_1254.aseprite): 기존 1254×1254 편집 원본의 참고 보관본.
- [idle_poses_imagegen.png](idle_poses_imagegen.png): 기존 1254 시험에서 내장 imagegen 편집 모드로 만든 포즈 시트의 참고 보관본. v002에서 새로 생성한 그림은 아니다.

색 정리 결과물은 [상위 폴더의 idle.aseprite](../idle.aseprite)와 [Frames](../Frames/idle_01.png)에 있다. v001 파일에 공통 불투명 26색 팔레트와 알파 이진화를 적용했으며 디더링은 사용하지 않았다. 결과 편집 파일은 Indexed 모드, 팔레트 27칸(투명 1 + 불투명 26)이며 반투명 픽셀은 0개다. [색 정리 명세](../../../Prompts/pixel_cleanup_spec.md)에 이번 처리 규칙을 기록한다.

출처 비교를 위해 이 보관본은 그대로 두고, v002의 키포즈 수정은 상위 폴더의 편집 파일에 진행한다. 기존 `Hunter_300/v001` 시험 폴더도 별도로 유지한다.
