# 생성 출처와 v003 직접 수정 규칙

v003은 이미지 생성 도구를 새로 호출하지 않고, [v002의 편집 원본](../Clips/HU-01_idle/Source/idle_300_v002.aseprite)의 픽셀을 직접 수정했다. 전체 팔레트 수를 줄이는 데 더해 같은 물체 안의 잔색을 합치고 녹색·모자 띠의 명암 면을 지정했다.

[pixel_cleanup_spec.md](pixel_cleanup_spec.md)는 이번 수정 규칙과 좌표 없이 표시 레이어로 영역을 전달하는 방법을 기록한 문서다. [재구성 스크립트](../QA/clean_planes.lua)와 [파일 검수 기록](../QA/file_validation.json)을 함께 확인한다.

처음 1254 포즈를 만들 때 사용한 [기존 생성 프롬프트](../../v002/Prompts/HU-01_idle.md)와 [포즈 시트](../../v002/Clips/HU-01_idle/Source/idle_poses_imagegen.png)는 출처 기록이다. 이번 직접 픽셀 수정의 실행 지시와 구분한다.
