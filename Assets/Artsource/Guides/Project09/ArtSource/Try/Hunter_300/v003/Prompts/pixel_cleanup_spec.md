# v003 직접 픽셀 수정 규칙

## 입력과 출력

입력은 [v002 보관본](../Clips/HU-01_idle/Source/idle_300_v002.aseprite), 출력은 [v003 idle.aseprite](../Clips/HU-01_idle/idle.aseprite)다. 300×300 캔버스, 두 프레임, 각 500ms, `idle` 반복 태그를 유지한다. 새 이미지·키포즈는 생성하지 않는다.

출력은 Indexed 모드의 공통 팔레트 17칸(불투명 16색 + 투명 1칸)을 사용한다. 두 프레임 모두 실제 불투명 16색이다. 입력의 투명 영역은 바꾸지 않으며 반투명 픽셀은 없다.

## 면 정리

모자·챙·목도리·몸통·양 소매·바지·다리·모자 띠·머리카락·화살통·끈·벨트·장갑·신발·활을 물체별 범위로 구분했다. 다른 물체와 투명 영역을 섞지 않고 같은 물체 안의 작은 명암 조각을 기본색으로 합친다.

녹색은 아래 세 색만 사용한다.

| 역할 | 색 |
| --- | --- |
| 기본 면 | `#487040` |
| 그림자 면 | `#355B32` |
| 밝은 면 | `#AEC95C` |

녹색 기본 면을 먼저 통일한 뒤 필요한 그림자 위치를 지정한다. 기존 밝은색은 충분히 연결된 면을 남긴다. 같은 물체 안의 고립된 색은 주변 다수 색으로 합치고 작은 명암 섬을 제거한다. 모자 띠의 명암도 별도 면으로 지정했다. 디더링·색 평균·그라데이션·새 중간색을 사용하지 않는다.

실제 구현은 [clean_planes.lua](../QA/clean_planes.lua), 최종 수치는 [file_validation.json](../QA/file_validation.json)을 기준으로 확인한다. 이 정리는 균일한 저해상도 도트 격자로 다시 그리는 작업을 포함하지 않는다. 기존 프레임 간 얼굴·모자 형태와 포즈 차이는 별도 보정 대상이다.

## 좌표 없이 수정 범위 전달하기

`idle.aseprite`에 별도 `색정리_지시` 레이어를 만들고, 원하는 프레임에서 통일할 면을 눈에 띄는 색으로 표시한 뒤 저장한다. 표시가 실제 파일에 남으므로 좌표를 적지 않아도 범위를 전달할 수 있다. 임시 선택 영역만 만들고 저장하는 방식에 의존하지 않는다. 표시 레이어는 최종 그림과 내보내기에서 제외한다.

다음처럼 지시한다.

> `색정리_지시` 레이어에 표시한 모자의 녹색 기본 면을 `#487040` 하나로 통일해줘. 그림자는 `#355B32`, 밝은 면은 `#AEC95C`만 사용해줘. 같은 면 안의 잔색·작은 색 조각을 없애고 의도한 명암 경계는 정리해줘. 실루엣과 눈·장비 형태는 유지하고, 새 이미지 생성 없이 기존 픽셀을 직접 수정해줘. 새 색·그라데이션·디더링·안티앨리어싱은 추가하지 마.

다른 물체도 표시 범위를 지정하고 기본색·그림자·밝은색을 [현재 팔레트](../Clips/HU-01_idle/Export/palette.json)에서 고른다. 전체 색 수 제한과 각 면을 단색으로 정리하는 지시는 함께 적는다.
