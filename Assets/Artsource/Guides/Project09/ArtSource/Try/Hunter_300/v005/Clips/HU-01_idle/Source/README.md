# idle v005 수정 전 원본

[idle_300_v004.aseprite](idle_300_v004.aseprite)는 [v004 편집 파일](../../../../v004/Clips/HU-01_idle/idle.aseprite)을 그대로 복사한 보관본이다. v005의 직접 픽셀 수정에 사용했다. 동일성은 [출처 해시 기록](../../../QA/source_hash.json)에서 확인한다.

보관본을 유지하고 수정은 [상위 폴더의 v005 idle.aseprite](../idle.aseprite)에 진행한다. 수정 전 프레임은 [v004 1번 PNG](../../../Reference/idle_v004_01.png)와 [v004 2번 PNG](../../../Reference/idle_v004_02.png)로 보관했다.

이전 생성 원본과 수정 이력은 [v004 출처 안내](../../../../v004/Clips/HU-01_idle/Source/README.md)에서 이어서 확인한다. v005에서는 이미지 생성 도구를 호출하지 않았다.
