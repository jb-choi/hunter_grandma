# v005 사용자 피드백과 직접 수정 규칙

사용자가 v004 확대 화면에서 여전히 남아 있는 이미지 돌출과 삐쭉한 선 경계를 지적했다. v005는 [v004 보관본](../Clips/HU-01_idle/Source/idle_300_v004.aseprite)의 눈 모양과 재질 경계를 직접 수정한 버전이다.

[contour_cleanup_spec.md](contour_cleanup_spec.md)에 피드백과 실제 수정 범위를 기록했다. [수정 스크립트](../QA/cleanup_v5.lua)와 [파일 검수 기록](../QA/file_validation.json)이 구현과 수치의 기준이다.

v004에서 기존 검정 윤곽과 투명 영역을 보호한 범위도 이번에는 필요한 위치에서 수정한다. 귀의 의도한 음영, 버클, 활줄처럼 형태를 설명하는 디테일은 별도로 보호한다. 볼터치는 1번 프레임의 경계 돌출 1픽셀만 수정하고 나머지를 보호한다.

이번 버전은 새 이미지 생성 프롬프트를 실행하지 않았다. 기존 이미지 생성의 출처는 [v004 출처 안내](../../v004/Clips/HU-01_idle/Source/README.md)를 따라 확인한다.
