# v005 직접 픽셀 수정 명세

## 사용자 피드백

> 아직 이미지 돌출이나 선의 경계 삐쭉빼죽은 여전한데

사용자가 첨부한 확대 화면에서 눈 가장자리에 다른 재질의 색이 남아 있고, 머리카락·윤곽 경계에 작은 돌출과 가는 색 띠가 보인다. 앞서 받은 디자인·포즈 유지, 작은 색 조각 통합, 불필요한 1픽셀 돌출·패임 정리, 형태 디테일과 의도한 명암 유지 지시는 계속 적용한다.

## 입력과 출력

입력은 [v004 보관본](../Clips/HU-01_idle/Source/idle_300_v004.aseprite), 출력은 [v005 idle.aseprite](../Clips/HU-01_idle/idle.aseprite)다. 300×300 캔버스, 두 프레임, 각 500ms, `idle` 태그를 유지한다. 기존 Indexed 팔레트 17칸(불투명 16색 + 투명 1칸)을 그대로 사용하며 새 색과 반투명 픽셀을 만들지 않는다.

## 수정 범위와 보호 기준

- 눈은 각 프레임에서 단색 검정 6×13px 직사각형으로 정돈한다. 1번 프레임은 `x=165~170, y=115~127`, 2번은 `x=168~173, y=114~126`이다. 눈 가장자리에 끼어 있는 녹색·갈색·피부색 잔색은 주변 피부 면이나 눈의 검정색으로 합친다.
- 얼굴 경계의 얇은 피부 그림자 띠를 기본 피부색으로 합친다. 귀의 의도한 음영은 제외한다.
- 1번 프레임의 얼굴 위쪽 경계 `(168,102)`와 `(169,102)`에 남은 갈색·녹색 잔점은 검정 윤곽으로 합친다.
- 모자 챙에 남은 녹색 띠와 머리카락에 끼어 있는 가죽색 띠를 해당 위치의 윤곽색으로 정리한다. 작은 머리카락·모자 잔점도 주변의 대표색으로 합친다.
- 다리에 남은 얇은 그림자 띠를 주변의 녹색 대표 면으로 합친다.
- 불필요한 경계 돌출과 패임은 기존 검정 윤곽 또는 투명 영역에 걸쳐 있어도 수정할 수 있다. v004처럼 해당 픽셀을 일괄 보호하지 않는다.
- 귀의 형태와 의도한 음영, 버클, 활의 가는 줄은 보호한다. 볼터치는 1번 프레임 `(165,129)`의 경계 돌출 1픽셀을 기본 피부색으로 합치고 나머지를 보호한다. 큰 명암 면과 전체 디자인·포즈·캐릭터 인상은 유지한다.

좌표는 원본 300×300 캔버스의 0부터 시작하는 픽셀 좌표이며 양 끝을 포함한다. 실제 범위와 처리 순서는 [cleanup_v5.lua](../QA/cleanup_v5.lua)를 기준으로 확인한다. 외곽 전체 또는 알파 마스크가 v004와 완전히 같다는 기준은 적용하지 않는다.

경계 정리는 두 차례 진행한다. 상하좌우에서 현재 색과 같은 이웃이 1칸 이하이고, 다른 후보색이 상하좌우 3칸 이상 및 주변 8칸 중 5칸 이상을 차지하는 픽셀을 후보색으로 합친다. 두 개의 같은 색 이웃으로 이루어진 의도한 직각 모서리와 별도 보호 범위는 유지한다. 모든 계단 경계를 일률적으로 재작성하는 규칙은 아니다.

새 이미지·키포즈 생성, 색 평균, 블러, 안티앨리어싱, 디더링은 사용하지 않는다. 기존 그림을 일정한 저해상도 도트 격자로 다시 그리는 작업은 포함하지 않는다. 기존 두 프레임의 형태·포즈 차이는 남아 있다.

## 검수 기록

[파일 검수 기록](../QA/file_validation.json), [원본 해시](../QA/source_hash.json), [편집 파일 재검수](../QA/native_validation.json), [재생기 검수](../QA/browser_validation.json)에 실제 변경 수치와 파일 확인 결과를 보관한다.

변경 픽셀은 1번 프레임 105개, 2번 프레임 149개다. 이 중 투명/불투명 경계가 바뀐 위치는 3개와 6개, 검정 윤곽이 바뀐 위치는 48개와 60개다. 위 볼터치 경계 1픽셀을 제외한 지정 보호 디테일의 불일치는 두 프레임 모두 0개다. 두 눈은 검정 6×13px 직사각형으로 확인했다. 각 프레임은 불투명 16색을 사용하고 반투명 픽셀은 0개다. 내보낸 PNG와 편집 파일 프레임의 픽셀 불일치는 0개다.

## 다음 수정 범위를 좌표 없이 전달하기

`idle.aseprite`에 별도 `색정리_지시` 레이어를 만들고 원하는 프레임의 수정 범위를 눈에 띄는 색으로 표시한 뒤 저장한다. 표시 레이어는 실제 그림과 내보내기에서 제외한다. 남길 대표색의 HEX, 유지할 디테일, 정돈할 경계 방향을 함께 적으면 범위를 명확히 전달할 수 있다. 임시 선택 영역만 만들고 저장하는 방식에는 의존하지 않는다.
