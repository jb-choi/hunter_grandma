# v004 직접 픽셀 수정 명세

## 사용자 지시

> 전체 디자인·포즈·캐릭터 인상은 유지해줘.
> 같은 면 안에 섞인 작은 색 조각, 가는 띠, 고립된 픽셀을 주변의 대표색으로 합쳐줘.
> 색 경계의 불필요한 1픽셀 돌출과 패임을 정리해서 계단 모양을 일관되게 만들어줘.
> 눈·귀 구멍·머리카락처럼 형태를 설명하는 디테일과 의도한 명암 경계는 유지해줘.
> 이미지 재생성 없이 기존 Aseprite 픽셀을 직접 수정하고, 블러·안티앨리어싱·디더링은 사용하지 마.
> V4

## 입력과 출력

입력은 [v003 보관본](../Clips/HU-01_idle/Source/idle_300_v003.aseprite), 출력은 [v004 idle.aseprite](../Clips/HU-01_idle/idle.aseprite)다. 300×300 캔버스, 두 프레임, 각 500ms, `idle` 태그를 유지한다. 기존 Indexed 팔레트 17칸(불투명 16색 + 투명 1칸)을 그대로 사용하며 새 색과 반투명 픽셀을 만들지 않는다.

## 수정 범위

- 귀 안쪽의 밝은 면은 `#FFF1D2` 한 색으로 정리한다. 귀의 주황색 내부와 갈색 테두리는 유지한다.
- 피부·깃털·손의 같은 면 안에 남은 작은 색 조각과 가는 띠를 주변 대표색으로 합친다. 화살 깃털에 섞인 녹색 잔색은 크림색으로 정리한다. 손의 연결된 명암 조각은 25픽셀 미만이면서 기본 피부색에 닿은 경우에만 기본색으로 합친다.
- 턱 아래 목의 잔색은 기본 피부색 `#FFD8A0`와 아래쪽 그림자 `#F5BB7B`로 정리한다. 목 영역의 변경 픽셀은 1번 21개, 2번 16개다.
- 같은 재질의 내부 색 경계에서 불필요한 1픽셀 돌출·패임을 보수적으로 정리한다. 같은 물체·색 계열 안에서 상하좌우 중 3칸 이상, 주변 8칸 중 6칸 이상이 같은 후보색인 픽셀을 두 차례 정리한다.
- 외곽 실루엣과 눈·얼굴의 볼 색 영역은 보호한다. 녹색과 머리카락의 큰 명암 면, 의도한 경계와 형태 디테일을 유지한다.

볼과 귀 안쪽의 주황색은 `(117, 100)`부터 `(196, 146)`까지의 얼굴 범위에서 보호한다. 턱 아래 목의 주황색 잔색은 위 목 정리 규칙에 따라 수정할 수 있다. 귀의 갈색 테두리와 인접 머리카락은 별도로 유지한다.

깃털 검토에서 두 위치를 추가로 정리했다. 1번 프레임 `(104, 70)`의 금색 잔점은 주변 갈색 `#AA5424`로 합쳤다. 2번 프레임 `(105~107, 70)`의 크림색 3픽셀은 깃털 경계의 주황색 `#F69B45`로 맞췄다. 이 좌표는 원본 캔버스의 0부터 시작하는 픽셀 좌표다.

새 이미지·키포즈 생성, 색 평균, 블러, 안티앨리어싱, 디더링은 사용하지 않는다. 기존 그림을 일정한 저해상도 도트 격자로 다시 그리는 작업은 포함하지 않는다. 프레임 간 얼굴·모자 형태와 포즈 차이는 남아 있다.

실제 범위와 픽셀 처리 규칙은 [cleanup_v4.lua](../QA/cleanup_v4.lua), 결과 수치는 [file_validation.json](../QA/file_validation.json)을 기준으로 확인한다. [원본 해시](../QA/source_hash.json), [편집 파일 재검수](../QA/native_validation.json), [재생기 검수](../QA/browser_validation.json)를 함께 보관한다.

변경 픽셀은 1번 프레임 383개, 2번 프레임 398개다. 두 프레임의 투명 영역·보호 디테일·기존 검정 윤곽 불일치는 0개이며, 반투명 픽셀은 0개다. 각 프레임은 실제 불투명 16색을 사용하며 팔레트는 v003과 정확히 일치한다.

## 다음 수정 범위를 좌표 없이 전달하기

`idle.aseprite`에 별도 `색정리_지시` 레이어를 만들고 원하는 프레임의 수정 범위를 눈에 띄는 색으로 표시한 뒤 저장한다. 표시 레이어는 실제 그림과 내보내기에서 제외한다. 남길 대표색의 HEX와 유지할 디테일을 함께 적으면 범위를 명확히 전달할 수 있다. 임시 선택 영역만 만들고 저장하는 방식에는 의존하지 않는다.
