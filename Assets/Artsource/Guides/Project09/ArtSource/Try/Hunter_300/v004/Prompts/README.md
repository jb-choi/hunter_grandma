# v004 사용자 지시와 직접 수정 규칙

v004는 [v003 보관본](../Clips/HU-01_idle/Source/idle_300_v003.aseprite)의 픽셀을 직접 수정한 버전이다. 전체 디자인과 포즈를 유지하면서 귀·피부·목·깃털·손의 작은 색 조각·가는 띠·고립된 픽셀과 불필요한 1픽셀 색 경계를 정리한다.

[pixel_cleanup_spec.md](pixel_cleanup_spec.md)에 사용자가 전달한 지시문과 실제 수정 범위를 기록했다. [직접 수정 스크립트](../QA/cleanup_v4.lua)와 [파일 검수 기록](../QA/file_validation.json)이 구현과 수치의 기준이다.

이번 버전은 새 이미지 생성 프롬프트를 실행하지 않았다. 기존 이미지 생성의 출처는 [v003 출처 안내](../../v003/Clips/HU-01_idle/Source/README.md)를 따라 확인한다.
