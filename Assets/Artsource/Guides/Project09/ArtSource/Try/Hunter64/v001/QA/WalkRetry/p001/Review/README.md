# WalkRetry 독립 입력 검수

2026-10-13. [입력 비교·해석](source_review.md) · [원시 픽셀 비교](source_comparison.json) · [부츠 전후·차이](lower_f01_before_after_diff_8x.png).

`walk_another` F1의 43점은 옷자락이 아니라 바짓단 7점·부츠 36점의 수정이다. 머리·상의·팔·장비는 현재 idle F1과 동일하다. 새 부츠는 뒤31px(x24..29/y51..56), 앞42px(x31..38/y51..56)로 나뉜다. 앞부츠 분할을 x≥31로 잡아 새 x31 외곽 5픽셀을 보존해야 한다.

후속 F2/F3는 단순 전파가 아닌 손·소매·몸 옆면·새총 기울기·다리 겹침의 수동 포즈다. 기존 walk의 빈 4프레임을 새 retry의 연속 포즈로 채우면서 몸 폭, 손–새총 접점, 골반–무릎–부츠와 자락 연결을 별도로 검수한다. 이번 입력 검수는 새 retry 완성 판정이 아니다. 원본 3파일과 다른 클립은 변경하지 않았다.
