# focus_rework2 Frame1 · 실루엣 분리 검수

이 문서는 **1F 부위 분리 당시 기록**이다. 후속8F는 [Focus8 검수](../Focus8/p001/visual_review.md), 당시1F 원본은 [보존본](../../../Source/Rework2/Focus8/p001/focus_rework2_base.aseprite)을 따른다. 아래 정적 이미지·수치는 당시 분리 결과의 근거다.

2026-10-13. [focus_rework2.aseprite](../../../focus_rework2.aseprite)의 1프레임·8레이어를 검수했다. 판정 범위는 원본 Frame1의 외형 유지, 부위별 단색화와 독립 레이어 구성이다.

## 실제 표시 전환

`build.lua`에서 작업본 저장·닫기 후 다시 열었다. 각 레이어만 visible인8상태와 한 레이어씩 숨긴8상태를 `States/*.aseprite`로 저장·재개봉하고 PNG로 렌더했다. 상태의 visible 목록과 경로는 [native_validation.json](native_validation.json)의 `states`에 있다. 정본은 전8레이어 visible 상태로 유지한다.

| 부위 / F1 | 단독·숨김 확인 내용 | 판정 |
| --- | --- | --- |
| 머리·모자 | 깃털부터 얼굴까지 하나의 노란 실루엣. 얼굴/눈/모자 명암색 없음. 원본의 외곽 유지. | 현재 분리 범위 통과 |
| 상반신 몸통 | 초록 한 색. 팔을 숨겨도 양쪽 상의 면이 이어짐. 팔 뒤37px 보완은 현재 팔 아래에 가려짐. | 현재 분리 범위 통과 |
| 왼팔 | 분홍 한 색. 소매→팔→손 외형 유지, 몸통 벨트가 과도하게 팔에 들어가지 않도록 행별 경계를 구분함. | 현재 분리 범위 통과 |
| 오른팔 | 하늘색 한 색. 어깨→굽힌 팔→그립 손을 분리. 새총/자루 색이 팔에 섞이지 않음. | 현재 분리 범위 통과 |
| 하반신 몸통 | 보라 한 색. 골반·자락 포함. 다리를 숨겨도 자락의 외형 유지. | 현재 분리 범위 통과 |
| 오른다리 | 주황 한 색. 부츠 포함, 자락 아래 보완한 허벅지가 단독 표시에서 이어짐. | 현재 분리 범위 통과 |
| 왼다리 | 파랑 한 색. 부츠 포함, 자락 아래 보완한 허벅지가 단독 표시에서 이어짐. | 현재 분리 범위 통과 |

처음 분할에서 보이는 다리/부츠만 있던 범위를 자락 아래 허벅지까지 보완했다. 이는 현재 자세에서 추정한 숨은 영역이며 앞의 자락을 통해 전체 외형은 유지한다. 새 조준 자세의 관절·팔 길이·새총 당김은 이 단계에서 평가하지 않았다.

## 파일·범위 확인

- native 재개봉:64×64 Indexed,8레이어,1F150ms,`focus_base`1~1,팔레트9칸/투명0.
- 각 레이어는 불투명 한 색만 사용하고 합성은 실제8색이다. 반투명 픽셀0.
- 원본 표시 Frame1과 결과 PNG의 알파 차이0, 불투명1082px. 원본 세부 색을 유지하는 검사가 아니라 사용자가 요청한 실루엣의 외형 보존 검사다.
- [독립 PNG 검사](independent_validation.json)에서 지정8색·원본 알파·입력/보존본 해시·16상태 파일 존재를 확인했다.
- 기존 `focus_rework.aseprite`의 바이트는 보존했다. 새 작업본만 만들었다.
- [제작 코드](build.lua), [비교·검수 이미지 생성](prepare_review.py)을 보관했다.

**현재 판정: Frame1의 8부위 단색 실루엣 분리 완료.** 원래64px와8배 합성,8부위 단독·숨김 상태에서 색/분할/외형을 확인했다. 정적1F이므로 재생·브라우저·동작 연결은 해당 없음이다. Focus 애니메이션 작화 완료 또는 Unity 적용 완료의 판정은 아니다.
