# 무릎 굽힘·옷자락 별도 프레임 · p001

2026-10-12. [walk.aseprite](../../../Clips/HU-02_walk/walk.aseprite)의 뒤에 F10·11을 비교용으로 추가했다. 기존 걷기 태그 `walk`는 F1~9, 새 태그 `knee_drape`는 F10~11이다. [작업 전 9프레임 native](../../../Clips/HU-02_walk/Source/WalkKneeDrape/p001/walk_before.aseprite)와 [해시](source_hash.json)를 보존한다.

| 새 프레임 | 기준 | 무릎·정강이 | 자락 |
|---|---|---|---|
| 10 | 기존 F3 · 왼쪽 발 통과 | 골반(28,48)→앞으로 나온 무릎(33,47)→뒤로 접힌 부츠 입구(30,50) | x30~33의 끝이 y47→46, 기존 녹색 명암으로 접힘 |
| 11 | 기존 F7 · 오른쪽 발 통과 | 골반(35,48)→앞으로 나온 무릎(38,47)→뒤로 접힌 부츠 입구(33,50) | x35~38의 끝이 y47→46, 기존 녹색 명암으로 접힘 |

두 포즈 모두 들린 발의 발바닥은 y55, 접지한 발은 y56이다. 앞쪽으로 나온 허벅지와 무릎 위의 옷자락만 국소적으로 올리고 어두운 밑면을 넣었다. 자락의 중앙 모양 x32~33/y45~46, 반대쪽 패널과 허리 디자인을 보존했다. 다리 전체의 단순 이동으로 굽힘을 대신하지 않았다.

`LowerBody`에서만 수정했다. 기존 4개 레이어의 이름·순서·불투명도·표시·블렌드를 유지하고 머리·상의·팔·장비 3개 레이어는 각 기준 F3/F7 셀과 같다. 이미지 재생성·블러·안티앨리어싱·디더링·색 보간은 사용하지 않았다.

|---|---|

| 올라온 허벅지 위의 자락 | 국소 1px 상승과 어두운 밑면 확인 |

| 들린 부츠와 접지 부츠 | 발바닥 y55/56으로 구분 |
| 64px·확대 검수 | F11의 꺾임이 더 뚜렷하며 F10은 미묘한 변형 |

독립 검수에서도 무릎과 자락 변형을 확인했다. F10의 (33,49)와 F11의 x30~33/y48~49 투명 부분은 옷 끝보다 아래에 있는 두 다리 사이 공간이다. F11의 x39 주변 빈 부분은 다리와 활 사이 공간이며 옷 내부 누락으로 판정하지 않았다. 이번 결과는 기존 걷기 포즈에 바로 전파하기 전 비교용 별도 프레임이다.
