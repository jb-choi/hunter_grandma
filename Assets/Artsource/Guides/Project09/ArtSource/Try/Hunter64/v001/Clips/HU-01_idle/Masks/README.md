# 64×64 부위 마스크

이 폴더는 Hunter_300 v006의 부위·보존 디테일 마스크를 64×64 출력 좌표에 대응시키는 자료를 보관한다. 캐릭터의 실제 팔레트와 마스크 식별 색은 별개의 값이다.

64×64 [material_regions.aseprite](material_regions.aseprite)와 [regions.json](regions.json)은 축소본의 부위 확인에 사용한다. 300×300 원본 마스크는 [Source/material_regions_300.aseprite](../Source/material_regions_300.aseprite), 원본 정의는 [Source/regions_300.json](../Source/regions_300.json)에 별도 보관한다. 출력 `(x, y)`의 입력 좌표는 캐릭터와 같은 `floor((x + 0.5) × 300 / 64)`, `floor((y + 0.5) × 300 / 64)`다. 색 보간을 하지 않아 부위 ID 사이에 중간 색을 만들지 않는다.

| 레이어 | 내용과 기본 표시 |
|---|---|
| `MaterialRegions` | 13개 재질·부위 식별, 표시 |
| `PreservedDetails` | 원본에서 지정한 눈·귀·버클·활줄의 보존 범위, 표시 |
| `EditableBoundaries` | 원본의 수정 가능한 경계 범위, 숨김 |

재질 ID는 깃털, 모자 본체·챙, 모자 띠, 머리카락, 얼굴·귀·목, 스카프·몸통, 가죽·끈·장갑, 손, 버클, 다리, 신발, 활·활줄, 화살·화살통에 대응한다. 레이어를 전환해 재질 면과 보존 범위를 구분한다.

`regions.json`의 `source_300_rectangles`는 원본 300px 좌표, `sampled_64_rectangles`는 샘플링으로 대응하는 64px 좌표다. 사각형은 `[x_min, y_min, x_max, y_max]`이며 네 경계 좌표를 포함한다. PNG 좌상단 원점이다.

| 64px 보존 범위 | 1번 프레임 | 2번 프레임 |
|---|---|---|
| 눈 | `[35, 25, 35, 26]` | `[36, 24, 36, 26]` |
| 귀 디테일 | `[28, 27, 31, 29]` | `[28, 26, 31, 28]` |
| 버클 | `[33, 41, 35, 43]` | `[35, 41, 37, 43]` |
| 활줄 창 | `[44, 32, 44, 48]` | `[44, 32, 44, 48]` |

이 사각형은 원본의 범위를 샘플링 좌표로 옮긴 값이다. 사각형 안의 모든 픽셀이 동일한 의미의 디테일이라는 뜻은 아니며 실제 보호 마스크는 `PreservedDetails` 레이어를 기준으로 확인한다.

원본에서 지정한 눈·귀·버클·활줄의 보존 범위도 같은 좌표 변환을 따른다. 마스크가 줄어드는 것만으로 해당 디테일이 가독성을 유지했다고 판단하지 않는다. 실제 결과는 [전신 시각 검수](../../../QA/visual_review.md)에서 확인한다.

이번 축소 시험에서 마스크는 부위와 보존 범위의 대응을 확인하는 자료다. 마스크 레이어를 캐릭터 그림 위에 합성하거나 export에 포함하지 않는다. 이후 직접 픽셀 정리를 추가하면 [공통 가이드](../../../../../../../Docs/AI/Art/02_Production/PixelCleanupGuide.md)에 따라 수정 범위와 변경 기록을 함께 갱신한다.
