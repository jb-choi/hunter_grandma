## 교차 발 수정과 실제 가림

초안에서는 F3 뒤발/F7 앞발이 -2y라 검정 투명배경에서 한 부츠처럼 읽히기 쉬웠다. 수정본은 두 교차 발을 -3y로 한 픽셀 더 들어 올리고 커프 연결과 해당 자락 끝을 맞췄다. 밝은 배경에서 재검수했고 다음 개선을 확인했다.

| 교차 | 초기 / 수정 부츠 템플릿 겹침 | 수정본의 독립적으로 보이는 source 색 픽셀 | 실제 판정 |
|---|---:|---|---|
| F3 뒤발 들림 | 18 / 14px | 뒤13px, 앞28px. 뒤발 독립 노출은 9→13px | 뒷부츠의 윗부분과 높이 차가 더 읽힌다. 앞쪽 지지 부츠와 일부 겹치는 것은 원근과 교차의 의도된 가림이다. |
| F7 앞발 들림 | 17 / 14px | 뒤17px, 앞23px. 지지 뒤발 독립 노출은 14→17px | 앞쪽의 들린 발끝은 y53, 뒤쪽 지지 발은 y56으로 구분된다. 높이 올린 앞부츠 윗부분 일부는 자락에 가려져 독립 노출이 25→23px로 줄지만 템플릿 누락이 아니다. |

위 독립 노출 값은 다른 부츠 템플릿과 겹치지 않으면서 실제 LowerBody에 같은 source 색으로 남은 좌표 수다. 이는 각 부츠의 전체 원본 픽셀 수나 모든 겹침에서의 색 구분 수가 아니다. 겹친 곳의 가림 순서와 자락에 덮인 부분을 부츠 삭제로 보고하지 않는다. 64px에서 교차 순간의 발이 완전히 떨어져 보이진 않지만, 들어 올린 발과 지지 발의 높이·발끝 변화가 구분된다.

## 수치 대응과 재생 범위

읽기 전용으로 다시 렌더한 native와 각 64px PNG는 전9프레임 불일치 0이다. 머리 정수 이동 불일치 0, 부분 alpha 0, 중앙 패임 변경 0이며 모든 프레임의 최저 불투명 좌표는 y56이다. [정적 대응 데이터](retry_static_checks.json)는 이 범위의 확인이고 태그·GIF·시트·원본 해시 전체 통합검사를 대체하지 않는다.

현재 파일은 source의 6개 레이어 순서 `backgroud_temp`, `Bow&Quiver`, `Slingshot&bag`, `LowerBody`, `UpperBody_Arms_Equipment`, `Head_Hat_Hair_Face`를 유지한다. 배경과 Bow&Quiver는 숨기고 새 장비와 몸3개 레이어를 표시한다. `walk` F1~8은 각120ms, 960ms 반복이며 `cycle_close` F9는 별도 참고다. 이미지 재생성·블러·안티앨리어싱·디더링을 사용하지 않은 기존 indexed 픽셀 작업이다.
