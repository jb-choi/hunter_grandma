## 부위별 확인

- 모자·깃털: 크라운·챙의 실제 두께와 뒤로 이어진 띠, 깃털의 부착 위치를 확인했다. 블록 표면의 계단과 원본 방향의 검정 외곽 재질은 의도한 스타일이다.
- 머리·얼굴: 머리·귀·코의 입체 면과 앞쪽 얼굴 재질, 뒤쪽 갈색 머리카락을 확인했다. 원본의 외곽·눈·명암은 실제 전면 큐브 면의 재질로 남아 있으므로 다른 시점에서도 일부 원본 도트 무늬가 보인다.
- 몸통·골반: 의상·벨트·끈을 입체 재질로 채우고 팔의 어깨/팔꿈치/손 위치를 따로 설정했다. 부위를 숨겨 드러난 접합 면은 부위 분할 때문에 보이는 정상 구성이다.
- 양다리·부츠: 골반 좌우의 별도 다리와 무릎·발목·부츠를 확인했다. 두 발은 공통 전방을 향한다. 기준 카메라에서 원본의 분리된 양발 위치가 나온다.
- 새총·가방: Y자 형태와 실제 두께, 손 접점, 뒤쪽 가방과 연결 끈을 확인했다.

검수 복사 세션에서만 hide_render 전환과 회전 카메라 변경을 수행했고 편집 정본의 기본 표시 상태를 바꾸지 않았다.

최종 판정: v003의 정적 3D 블록 구조와 원본 F1 정사영 대응 검수 통과. 미제공된 뒤·옆 디자인은 단일 원본에서 추정한 시안이다. 조명 렌더 자체의 색 일치, 완성 리깅, 애니메이션, 게임용 최적화까지 통과한 의미는 아니다.
