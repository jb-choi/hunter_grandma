## 실측 범위

좌표는 원본 PNG 좌상단 원점, 우측·아래쪽 증가, 반열린 구간 `[x0,y0,x1,y1)`이다. 알파가 128 이상인 픽셀을 사용했으며 아래 시점 이름 글자는 제외했다. 이 측정에는 도안의 어두운 테두리도 포함된다.

| 시점 | 캐릭터 바운딩박스 | 크기 |
| --- | --- | --- |
| FRONT | (186,85)–(545,597) | 359×512px |
| BACK | (711,85)–(1068,597) | 357×512px |
| LEFT | (177,670)–(536,1167) | 359×497px |
| TOP | (711,785)–(1113,1078) | 402×293px |

LEFT는 FRONT보다 높이가 2.93% 작고 TOP은 FRONT보다 가로 범위가 11.98% 크다. 시트의 모든 그림을 같은 배율의 정확한 정사영으로 바로 취급할 수 없다. TOP에는 모자·깃털·장비가 강조되어 있어 평면 배치 참고로 사용해야 한다.

## 비정규 픽셀 격자

도안의 명목 셀은 약 10px이다. 그러나 알파·색에 미세 변동이 있고 부위의 사각형 폭·높이가 서로 다른, 생성된 픽셀 스타일 이미지다. 1254px 캔버스 크기나 단일 셀 간격을 원래의 정확한 논리 도트로 선언할 근거는 없다.

FRONT의 검정 눈 직사각형 실측(`alpha≥128`, `max(R,G,B)<60`):

- 화면 왼쪽 눈: (323,271)–(333,303), 10×32px.
- 화면 오른쪽 눈: (380,267)–(391,303), 11×36px.

두 눈의 폭과 윗변 높이가 다르므로 하나의 10px 정규 격자에서 원본 좌표를 모두 정확하게 재현할 수 없다. 눈은 외곽선 제거 대상과 구별하여 보존한다.

FRONT의 주요 직선 경계 예:

- 모자 정상: y=85, x=344..395. 다음 단 y=95에서 x=314..343 영역이 들어온다.
- 부츠 주요 X경계: 265, 276, 286–288, 323, 334 및 363, 373–374, 411, 431, 442.
- 공통 밑창 띠: y=587..596, 아래 경계 y=597.

선택한 주요 X경계 35개에 대해 간격 후보 9.60–10.60px를 0.01px씩 검색하고 각 간격의 위상 100개를 검색했다. 최근접 격자선 오차 제곱을 9에서 상한 처리한 평균을 최소화한 근사는 **pitch=9.78px, phase=1.3692px** (`x=phase+n×pitch`)다. 절대오차 중앙값은 0.8092px, 최대값은 4.2692px이다. 선택 경계에 대한 근사이며 원본에 존재하는 확정 격자 또는 전체 이미지 최적값이 아니다.

v005의 첫 정면 정규화 후보는 제작자가 선택한 **pitch X=9.775px/Y=9.725px, phase X=1.4px/Y=2.6px**다. 이는 제작 좌표계이며 실측으로 입증된 원본 격자와 구별한다. 실제 정규화 타깃과 렌더 비교는 별도 QA에서 수행해야 한다.

## 앞뒤 동시 투영의 모순

불투명한 같은 물체를 정확히 반대 방향의 동일 배율 정사영으로 보면 실루엣은 좌우 반전 후 같아야 한다. 색·가림 순서는 달라도 실루엣에는 이 조건이 적용된다.

각 FRONT/BACK 바운딩박스를 기준으로 BACK 마스크를 좌우 반전하고, 수평 이동 ±12px·수직 이동 ±4px를 정수 단위로 검색했다. 최적 정렬은 **dx=+1px, dy=0px**였다.

| 항목 | 픽셀 수 |
| --- | ---: |
| FRONT 면적 | 116,804 |
| BACK 면적 | 114,157 |
| 교집합 | 112,921 |
| 합집합 | 118,040 |
| 서로 다른 마스크 픽셀 | 5,119 |

최적 IoU는 **0.956633**, 불일치는 합집합의 **4.337%**다. 예를 들어 각 bbox 상단에서 380px 아래인 가방·손 근처에서 FRONT 범위는 x=30..311, 반전 BACK 범위는 x=56..303이다(정렬 전 bbox 상대좌표). 단순 평행 이동으로 네 도안을 동시에 정확하게 만족시킬 수 없다.

## v005에 적용할 제약 우선순위

1. FRONT를 주 기준으로 삼고 도안의 실루엣·색 영역·눈·버클·손·새총의 평면 배치를 직접 정규화한다. 임의 원형 두상이나 곡선 부피를 새로 투영해 도안을 대체하지 않는다.
2. LEFT는 높이와 접지점을 정렬한 뒤 부위별 깊이·앞뒤 위치를 정하는 데 사용한다.
3. TOP은 모자·깃털·장비의 평면 위치를 정하는 참고 제약으로 사용한다.
4. BACK은 후면 색·띠·머리카락·장비 배치를 참고한다. FRONT와 충돌하는 실루엣은 FRONT에 우선권을 준다.

사용자의 무테 요구는 어두운 윤곽 재질을 부위 색으로 바꾸되 도안의 배치를 유지하는 것으로 적용한다. 검정 눈과 버클 구멍 등 의미 있는 디테일은 별도로 보존한다. 이 분석은 투영 가능성의 한계와 제작 기준을 기록하며 모델 완성 또는 검수 통과를 뜻하지 않는다.
