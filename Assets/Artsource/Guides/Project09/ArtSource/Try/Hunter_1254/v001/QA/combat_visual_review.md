# 전투·수집 클립 시각 검토

검토 대상: HU-03 focus, HU-04 shoot, HU-05 collect. 생성 원본 시트와 정규화된 contact 시트를 비교했고 `focus_04.png`, `collect_03.png`의 1254×1254 개별 프레임도 확인했다. 이미지 수정 없이 검토했다.

## 확인 결과

| 클립 | 원본 포즈 보존 | 주요 판독 결과 |
|---|---|---|
| focus | 네 포즈의 모자·깃털·활·화살·부츠 잘림 없음 | 들기→메기기→당기기→완전 조준 순서가 읽힘. 3·4번은 팔 확장량 차이로 구분됨. |
| shoot | 1번 화살 끝과 네 포즈의 부츠 모두 보존 | 놓기→반동→활 내리기→대기 복귀 순서가 읽힘. |
| collect | 네 포즈의 손끝·부츠·깃털 보존 | 굽힘·웅크림이 원본처럼 낮아지며 웅크린 포즈가 선 포즈 높이로 늘어나지 않음. |

정규화에서는 생성 시트의 실제 빈 구간으로 분할하여 627px 균등 행/열 분할의 잘림 문제를 피했다. 고정 배율을 클립 내부에서 적용했고 얼굴·복장 정체성은 원본과 대응된다.

GIF 파일의 프레임 메타데이터 확인: 384×384 미리보기, 각각 4프레임. focus 150ms×4, shoot 100ms×4, collect 150ms×4. 이는 파일 구조/순서 확인이며 연속 재생의 부드러움을 승인한 것은 아니다.

## 채택 전 보정할 아트 항목

- focus: 당긴 시위가 얼굴과 모자 앞을 통과하고 일부 손·시위 접점이 복잡하다. 조준 시위 구조를 정리하면 동작이 더 또렷해진다. 활의 크기/곡률도 대기 자세와 완전히 같지는 않다.
- shoot: 1번 포즈 안에 화살이 남아 있다. F01 release 이벤트를 사용하되 별도 런타임 발사체와 중복되지 않도록 화살 분리를 검토한다. 2번 뒤쪽 손가락은 작은 출력에서 복잡하게 보인다.
- collect: 생성 원본에서 활이 생략되었다. 빈손 수집 동작은 읽히지만, 정식 적용에는 활을 등 뒤 부착물로 바꾸는 전환이 필요하다. F03 pickup 이벤트 위치는 낮게 뻗은 손과 대응한다. 손끝이 부츠보다 조금 낮은 포즈이므로 바닥 기준은 실제 발 위치를 별도로 확인하면 좋다.
- 클립 간 모자/얼굴의 세부 픽셀 군집·장비 모양은 생성마다 조금 달라진다. 일관된 원화나 장비 레이어로 정리하기 전까지 실험본으로 평가한다.

1254×1254는 최종 개별 프레임 캔버스 크기다. 입력 생성물은 1254×1254 전체 시트 안의 네 포즈이며, 각 포즈를 확대하고 배치해 프레임을 만든다. 고해상도 캔버스 자체가 추가 원화 디테일이나 애니메이션의 부드러움을 보장하지는 않는다.
