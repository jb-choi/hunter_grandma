# HU-05 collect — 원본 포즈 시트

`collect_poses_imagegen.png`: built-in image_gen 투명 배경 원본 1254×1254. 2열 × 2행, 좌→우·위→아래 순서.

1. 내려다보며 서 있는 대기 자세.
2. 허리와 무릎을 굽혀 손을 내미는 자세.
3. 낮게 웅크려 바닥에 손을 뻗는 자세.
4. 일어나 두 손을 모아 들어 올리는 자세.

시각 검토: 네 단계가 분명하고 원본 복장·얼굴을 유지. 별도 동물/아이템은 없으며 손도 확인된다. 원본의 활은 수집 자세에서 생략되었으므로 정식 전환 시 활을 등 뒤 부착물로 처리하는 정책을 검토해야 한다. 상단 두 포즈의 부츠가 균등 행 경계 y=627을 약간 넘으므로 y=645 전후의 빈 구간을 실제 분할선으로 사용해야 잘림을 피한다. 정규화에서는 원본 전체 키가 아니라 머리 크기를 기준으로 웅크린 포즈의 크기를 유지한다.
