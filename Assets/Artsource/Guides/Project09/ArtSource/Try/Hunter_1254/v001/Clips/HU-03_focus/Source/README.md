# HU-03 focus — 원본 포즈 시트

`focus_poses_imagegen.png`: built-in image_gen 투명 배경 생성 원본. 2열 × 2행, 좌→우·위→아래 순서.

1. 활을 들기 시작하는 대기 자세.
2. 활을 세우고 화살을 메기는 자세.
3. 화살을 당기는 중간 조준 자세.
4. 끝까지 당겨 오른쪽을 겨누는 자세.

시각 검토: 네 포즈와 캐릭터 정체성은 확인. 3·4번은 팔이 더 뻗는 차이로 구분되며, 활시위 일부가 얼굴/모자 앞을 지나므로 정식 채택 전 손·시위 연결을 보정해야 한다. 4번 화살 끝이 셀 오른쪽에 가까우나 잘리지는 않았다. 상단 부츠가 균등 경계 y627을 조금 넘으므로 y645 부근 빈 구간으로 행을 분할한다. 이 시트는 애니메이션 실험용 키포즈이며 1254×1254 개별 프레임으로 정규화할 원본이다.
