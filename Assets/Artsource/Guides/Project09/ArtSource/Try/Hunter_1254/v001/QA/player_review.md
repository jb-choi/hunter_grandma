# 애니메이션 검토 플레이어 QA

2026-10-11 · 대상: `Previews/index.html`, `Previews/manifest.json`

**8개 동작의 이미지 디코딩·프레임 이동·루프/단발 재생과 비교 크기를 확인했다. 데스크톱과 모바일 화면을 렌더링해 검토했고, 발견한 썸네일 및 모바일 잘림 문제를 수정한 뒤 재검증했다.** 작화의 루프 연결 품질이나 Unity 적용을 승인한 기록은 아니다.

## 검사 방법과 근거

- 번들 Node.js/Playwright와 별도 headless Edge를 사용해 로컬 HTML 결과물을 검사했다. 사용자의 기존 브라우저 세션은 조작하지 않았다.
- 재현 스크립트: [render_review.cjs](render_review.cjs)
- 실제 검사 결과: [browser_validation.json](browser_validation.json)
- 시각 검토 화면: [데스크톱 1360px](player_desktop.png), [모바일 390px](player_mobile.png)
- 앞선 파일 검사에서 페이지·manifest·참고 원본·32 비교본·36프레임, 총 40개 경로가 HTTP 200이었다. 36개 PNG는 모두 1254×1254이며 [파일 검수](file_validation.json)와 [Aseprite 검수](aseprite_validation.json)에 규격·프레임 수·duration을 기록했다.
- 브라우저 검사 중 JavaScript 오류와 HTTP 실패 응답은 없었다.

## 재생 확인

| 태그 | 프레임 | 1회 duration | 확인한 재생 규칙 |
| --- | ---: | ---: | --- |
| `idle` | 2 | 1000 ms | 계속 반복 |
| `walk` | 6 | 720 ms | 계속 반복 |
| `focus` | 4 | 600 ms | 마지막 포즈에서 정지·유지 |
| `shoot` | 4 | 400 ms | 단발 후 마지막 프레임에서 정지 |
| `collect` | 4 | 600 ms | 단발 후 마지막 프레임에서 정지 |
| `carry_small` | 6 | 840 ms | 계속 반복 |
| `drag_large` | 6 | 960 ms | 계속 반복 |
| `load` | 4 | 1000 ms | 단발 후 마지막 프레임에서 정지 |

모든 클립을 선택해 PNG가 1254×1254로 디코딩되는지 확인하고, 다음/이전 프레임 이동과 1회 duration 이후의 재생 상태를 검사했다. `load_complete`는 F04 시작에서 활성화되지 않고 1000ms 종료 이벤트에서 활성화되었다. 「단발 동작도 반복 시연」을 켰을 때 반복 재생되며 2배속 선택이 상태에 반영됨을 확인했다.

## 비교 크기와 레이아웃 확인

- 42px 선택에서 고해상도 걷기의 기준 높이 41.993px, 32 비교본 42px를 측정했다. CSS 픽셀 반올림 범위에서 동일한 높이다.
- Point/Bilinear 전환과 크림 배경을 확인했다. 데스크톱 화면에서는 320px 기준 높이와 나란히 비교하는 구성을 검토했다.
- 썸네일은 무대 이미지와 별도 객체를 사용한다. 8개 클립 모두 썸네일이 60×60, 정상 문서 흐름을 유지하며 무대의 위치·크기 스타일을 전달받지 않는지 검사했다.
- 390px 모바일 화면에서는 두 비교 무대를 세로로 쌓는다. **8개 클립의 36프레임 모두** 보이는 픽셀 범위가 무대 안에 들어오고 페이지에 수평 넘침이 없음을 확인했다.
- 작은 화면의 맞춤 크기는 같은 클립 전체의 최대 범위로 계산한다. 클립 안에서 프레임마다 배율이 변하지 않고 32 비교본에도 동일한 기준 높이를 적용한다. 요청 320px일 때 모바일 적용 높이는 동작에 따라 약 262~306px였으며 화면에 실제 높이를 표시한다.

## 검사 범위

CUA에는 사용 가능한 브라우저가 없었으나, 이후 별도 headless Edge로 위 결과물 검사를 수행했다. 이 기록은 로컬 플레이어와 출력 파일에 대한 검증이다. 실제 게임 상태 전환, 동물/수레 부착, 장비 분리, Unity 메모리 및 프레임 간 작화 일관성은 별도 적용·보정 작업으로 남아 있다.
