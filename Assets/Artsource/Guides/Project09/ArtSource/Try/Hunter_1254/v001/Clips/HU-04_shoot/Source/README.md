# HU-04 shoot — 원본 포즈 시트

`shoot_poses_imagegen.png`: built-in image_gen 투명 배경 원본 1254×1254. 2열 × 2행, 좌→우·위→아래 순서.

1. 시위를 놓는 발사 순간. 화살은 활 끝에 짧게 남음.
2. 뒤쪽 손을 펴고 활이 조금 내려가는 반동 자세.
3. 활을 대각선으로 내리는 자세.
4. 원래 선 자세로 돌아온 대기 자세.

시각 검토: 네 포즈 구분, 원본 정체성, 활 내리기 복귀가 확인된다. 1번 화살이 x627 중앙 경계를 넘지만 다음 캐릭터와 겹치지는 않으므로 실제 빈 구간 x690 전후로 열을 분할해야 한다. 행은 y640 전후의 빈 구간을 사용하면 상단 부츠를 자르지 않는다. 1번 화살이 원본에 남아 있으므로 별도 발사체 런타임과 중복되지 않게 정식 채택 시 분리/제거 검토가 필요하다. 2번 뒤쪽 손가락 모양은 명확하나 손의 복잡한 형태를 정식 애니메이션에서 정리할 수 있다.
