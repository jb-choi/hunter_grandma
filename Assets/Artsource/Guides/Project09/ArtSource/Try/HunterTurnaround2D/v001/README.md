## 해석 기준

FRONT/BACK/LEFT는 같은 서 있는 자세를 다른 쪽에서 본 모습이다. FRONT의 새총은 화면 오른쪽, BACK에서는 화면 왼쪽으로 나타나도록 캐릭터의 왼손으로 해석했다. LEFT는 코가 화면 왼쪽을 향하는 캐릭터의 왼쪽 측면이다. TOP은 모자의 윗면·손·장비·가방·발의 배치를 보는 위쪽 시안이다.

깃털의 정확한 부착 쪽, 가방의 숨은 부착 면과 뒷머리·모자 위쪽 형태는 원본 한 장에서 확정할 수 없으므로 **디자인 제안**이다. 정면의 두 눈과 옆·뒤 면도 추가 시점으로 해석해 그렸다. 원본 자체를 수정하거나 추가 시점을 원본의 관찰 사실로 선언하지 않았다.

## 현재 상태

2D 다방향 **디자인 시안**. 3D 제작 전 시점 간 모순을 검토할 참고 자료다. 원본 팔레트의 정확한 17칸 제한이나 64×64 논리 격자로 납품하는 게임용 픽셀 정본으로는 아직 정리하지 않았다. 추가 시점의 세부 비율·부착 위치는 다음 설계 단계에서 조정할 수 있다.
