# LH-01 v001 시안 검토

검토일: 2026-10-12. 생성 결과를 전체 화면으로 시각 검토했다. 아래 판정은 컨셉 구도에 한정하며 픽셀 정리·게임 적용 검수 통과를 뜻하지 않는다.

![검토 대상](../Concept/hunting_idle_LH-01_loghouse_concept_v001.png)

| 항목 | 관찰과 판정 |
| --- | --- |
| 원본 구도 | 중앙 오두막, 외부 좌측 개집, 외부 우측 수레의 관계 유지. 스케치의 큰 하늘 여백은 줄였다. |
| 무기 | 좌측 벽의 활과 화살이 식별된다. 단계 교체용 분리 자산은 미제작. |
| 도감·수집 | 사슴/여우 사진, 기념품 선반, 펼친 동물 도감이 보인다. 실제 해금·클릭 기능은 미연결. |
| 탐색 도구 | 책상에 쌍안경과 원형 돋보기 표현이 보인다. 돋보기는 거치형 거울처럼도 읽힐 수 있어 정식 소품에서는 손잡이와 렌즈 형태를 명확하게 조정할 필요가 있다. |
| 사냥개 | 우측 실내 잠자리에서 쉬는 한 마리, 외부 개집은 별도로 표현. 휴식 애니메이션 미제작. |
| 수레 | 우측에 주차되어 바퀴와 적재함·손잡이를 식별할 수 있다. 최대 성장 외형과 여유 공간 실측은 미검수. |
| 추가 아이템 | 중앙 바닥과 일부 벽에 비어 있는 면이 있다. 25% 여유를 프롬프트로 요청했지만 실제 비율을 계측하거나 최대 단계 배치로 검증하지 않았다. |
| UI 분리 | 배경에 아이템 변경 화살표·버튼·가격·레벨 텍스트가 없다. 별도 게임 UI는 미제작. |
| 분위기 | 목재·따뜻한 등불·차분한 숲으로 생활 공간을 표현한다. 벽난로와 창문 등은 생성 컨셉의 제안 요소이며 확정 구조가 아니다. |
| 픽셀 제작성 | 도트풍 생성 컨셉이다. 전 영역의 일정한 픽셀 격자, 색수, 경계와 레이어를 검증하지 않았다. 완성 게임용 픽셀 자산으로 판정하지 않는다. |
| 해상도 | 출력 1672×941. 640×360 / 960×540 / 1280×720 실제 게임 화면 검수는 수행하지 않았다. |
| 원본 보존 | 입력 KRA를 별도 Source에 복사하고 SHA256을 기록했다. 원본 덮어쓰기 없음. |

선택 전 남은 작업: 구도 선택, 실제 표시 크기 검수, 도구 실루엣 명료화, 최대 단계 소품 배치, 정식 픽셀 규격과 레이어 분리 계획.
