## 발견한 문제와 처리

v003을 실제로 한 레이어씩 단독 표시했을 때, 배경의 반복 복원 띠/소품 자국, 수레의 잔디·바퀴 사이 배경과 등불 받침 분리, 소파 상단의 벽 픽셀이 확인됐다. 기존 합성 대 PNG 0픽셀 검사는 이런 문제를 잡는 작화 검수를 대신하지 못했다.

첫 직접 배경 복원은 사각형 패치가 눈에 띄어 검수 실패로 기록했다. 최종 배경은 내장 image_gen으로 기존 컨셉에서 소품이 없는 빈 오두막 배경판을 보완하고, Aseprite에서 640×320/기존 92색으로 매핑했다. 생성 프롬프트는 [Reference/background_plate_prompt.txt](Reference/background_plate_prompt.txt). 창·벽난로·고정 가구/조명·식물·러그를 유지하는 방향으로 검토했으며 배경의 일부 디테일은 이전 버전과 달라졌다.

소품은 재생성하지 않았다. v003 픽셀을 Aseprite/Lua에서 영역별로 직접 수정해 액자·도구 주변 여백, 활줄, 소파의 벽 픽셀, 수레의 바퀴 구멍/접점과 잔디를 정리했다. 색상 판단은 수레의 수작업 영역/바퀴 범위 안에서 잔여 배경을 지우는 보조 기준으로 사용했고, 모든 레이어를 시각적으로 다시 확인했다.
