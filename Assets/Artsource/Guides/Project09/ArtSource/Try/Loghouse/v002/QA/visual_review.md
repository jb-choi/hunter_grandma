## 시각 검토

| 영역 | 판정 |
| --- | --- |
| 건물·지붕·숲 | 원본 구도 유지. 576×320에 모두 들어간다. Nearest와 제한 팔레트로 픽셀 경계를 유지한다. 전체 숲의 작은 색 조각을 수작업으로 정리한 상태는 아니다. |
| 활·화살통 | 활의 굴곡과 화살이 보인다. 분리 레이어가 있으며 64×128 출력. 활줄과 주변 목재 픽셀의 완전한 분리는 후속 리터치 대상. |
| 사슴·여우 액자 | 서로 다른 동물 초상이 식별된다. 액자별 64×64 출력. |
| 도감·기념품 | 펼친 책과 조각 장식이 보인다. 작은 글자는 실텍스트가 아니라 그림 요소이며 실제 도감 설명 UI는 별도. |
| 돋보기·쌍안경 | 각 64×64 출력. 렌즈와 쌍안경 두 경통이 보인다. 돋보기는 원 컨셉의 거치형 형태를 유지했으며 휴대형으로 재설계하지 않았다. |
| 사냥개 | 머리·등·다리·잠자리를 유지. 실제 실루엣 75×35 영역을 128×64 셀에 담았다. 잠자리와 개는 같은 레이어다. |
| 개집 | 지붕·입구·바닥이 보인다. 128×128 출력. 가장자리 풀과 바닥 일부를 함께 추출했다. |
| 수레 | 바퀴·적재함·손잡이·등불을 유지. 128×128 출력. 바퀴 사이와 손잡이 아래의 배경 픽셀은 완전한 제거 전 준비 상태다. |
| 여유 공간 | 중앙 바닥과 우측 일부 벽을 유지. 최대 단계 소품을 추가한 게임 화면 검수는 미수행. |
| 복원 배경 | 소품을 숨긴 배경에 복제 질감과 접합이 남는다. 기본 합성에서는 추출 소품이 원래 위치를 덮어 원본 구도와 일치한다. 다른 크기의 소품으로 교체할 때 추가 보정 필요. |
| 버튼 | PNG에 변경 버튼·가격·레벨 없음. |

## 파일 재읽기 검증

- 저장된 `.aseprite`를 다시 열어 576×320, 기본 64×64 격자 원점 (0,0), 9×5칸 확인.
- 14레이어, 정적 1프레임(100ms), `idle_layout` 태그, 소품 10개 slice 확인.
- 기본 표시 합성: 실제 94색, 184,320픽셀 모두 불투명. 원본 정규화 이미지와 차이 0픽셀.
- `.aseprite` 재읽기 합성과 PNG export 차이 0픽셀.
- 소품 10개 모두 가로·세로가 64의 배수인 독립 PNG로 확인.
- 숨긴 참조/가이드는 최종 합성 PNG에 포함되지 않는다. 픽셀 리터치 레이어는 비어 있는 편집 공간이다.
- 상세 결과: [파일 검사](file_verification.json), [소품 검사](props_verification.json), [원본 해시](source_hashes.json).

검수 한계: 애니메이션 없음. 640×360 / 960×540 / 1280×720 실제 Unity 렌더는 실행하지 않았다. 모든 소품을 크게 이동한 상태의 경계 정리와 장비 단계 전량 제작은 후속 작업이다.
