큰 봉우리는 640px 주기마다 되풀이된다. 한 장 반복이라는 확정 규격의 특성으로 남긴다. 반복 다양화를 위한 다른 산 변형은 이번 범위에 없다.

## 파일 검수

- 저장된 Aseprite를 다시 열어 합성 PNG와 **230,400픽셀 전체 일치**, 차이 0픽셀을 확인했다.
- 원본 640×360, 정적 1프레임, 보이는 레이어 4개, 합성 알파 전부 255.
- 분리 PNG와 각 원본 레이어가 픽셀 단위로 일치하며 반투명 경계 픽셀 없음.
- GIF는 640×360, 80프레임, 무한 반복, 프레임당 160ms. 전체 프레임을 PNG의 순환 이동과 독립적으로 비교한다.
- 경계의 RGB 평균 변화량은 약 6.108/255다. 일반 내부 열 변화의 중앙값 5.563, 95백분위 12.377과 함께 기록했으며, 수치만으로 작화 연결을 판정하지 않았다.
- 파일 검수 상세: [native_validation.json](native_validation.json), [independent_audit.json](independent_audit.json).

## 한계와 적용 상태

- 이동 GIF의 프레임 픽셀 검수와 정적 순환 위치를 확인했다. HTML은 앱 내 브라우저의 로컬 파일 보안 정책 때문에 실제 UI 조작 검수를 수행하지 못했다. JS 문법과 상대 경로 자산 존재 여부를 확인한다.
- 현재 게임의 사냥꾼·동물·UI와 합성한 검수, Unity 화면 적용, 서로 다른 속도의 레이어 이동 검수는 수행하지 않았다.
- 편집 레이어의 먼 능선 밑칠은 주봉 뒤의 기본색이다. 가려진 원경 전체의 추가 작화 완료를 의미하지 않는다.
