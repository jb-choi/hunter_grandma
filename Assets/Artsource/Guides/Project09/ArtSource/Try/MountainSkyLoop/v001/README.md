# BG-01+02 · 하늘과 산 원경 · v001

상태: **레이어 작화 수정 필요 · Try 시안 · Unity 미적용**. 2026-10-12, Asia/Seoul.

사용자가 요청한 visibility 전환 단독 검수를 추가했다. **하늘만 통과, 구름·먼 능선·주봉과 산림은 미통과**로 판정했다. 기존 완료 판정을 정정한다. [레이어 단독 검수와 실제 표시 상태](QA/LayerReview/README.md)를 현재 작화 준비 상태의 기준으로 사용한다. 파일 형식·PNG 일치 검증 통과와 레이어 작화 판정을 구분한다.

후속 수정본: [v002](../v002/README.md). v001은 수정 전 원본·판정의 기록으로 보존한다.

## 확정 규격

- 캔버스: **640×360px**, 정적 1프레임.
- BG-01 하늘/밝은 공기색과 BG-02 먼 산·숲을 합친 불투명 원경.
- 사용자가 제공한 화강암 산 사진을 풍경의 참고로 사용한다.
- 큰 면으로 정리한 세밀한 픽셀 일러스트. 낮은 원경 대비, 좌상단 광원.
- 좌우 이동·반복용. 양끝 능선, 구름, 산림, 하늘색의 연결을 검수한다.
- 편집 원본에서 하늘, 구름, 먼 능선, 주봉·산림을 분리한다. 합성 PNG는 1장으로 출력한다.
- 사진 앞쪽의 소나무·바위·꽃, 길·캐릭터·소품·UI는 제작 범위에 포함하지 않는다.

## 결과와 제작 과정

- [합성 PNG](Export/bg_mountain_sky.png): 640×360, 전체 불투명, 실제 사용 RGB **42색**.
- [편집 원본](bg_mountain_sky.aseprite): RGB, 정적 1프레임, 보이는 4개 레이어. 팔레트는 투명 항목을 포함한 49항목이다.
- [가로 3회 반복 비교](Previews/repeat_3x.png), [경계 확대](Previews/seam_2x.png), [2배 확대](Previews/art_2x.png).
- [이동 GIF](Previews/scroll_preview.gif): 80프레임, 8px 이동/160ms, 12.8초 가로 반복. 정적 원본과 별도의 미리보기다.
- [조작 가능한 HTML](Previews/scroll_preview.html): 속도, 방향, 재생/정지, 위치, 1·2배 표시, 경계 표시. 기본 속도 16px/s. 주변 Export/Previews 폴더를 함께 유지하면 일반 브라우저에서 상대 경로 이미지를 읽는 구조다. 앱 내 브라우저는 `file:` URL을 보안 정책으로 차단하여, 실제 브라우저 조작 검수는 수행하지 못했다.
- [작화 검수](QA/visual_review.md), [원본 재조회 검증](QA/native_validation.json), [독립 파일 감사](QA/independent_audit.json).

1. 사용자 사진을 참고하여 하늘·화강암 주봉·낮은 능선·산림을 ImageGen으로 생성했다. [최초 프롬프트](Source/prompt.txt), [생성 원본](Source/imagegen_original.png)을 보존했다.
2. Aseprite 최근접 방식으로 최종 640×360 캔버스를 만들었다. 원본의 극소량 비율 차이(1672×940)는 이 단계에서 16:9로 맞췄다.
3. 좌우 경계를 중앙으로 옮겨 ImageGen으로 연결부를 보정했다. [보정 프롬프트](Source/seam_prompt.txt), [보정 생성 원본](Source/imagegen_seam_repair.png)을 보존했다.
4. 겹치는 영역에서 색 차이가 작은 연속 경로로 보정본을 연결했다. Aseprite에서 픽셀을 선택하여 조립했으며, 블러·평균 혼합·디더링을 쓰지 않았다. 주봉과 중앙 구도는 최초 시안을 유지했다.
5. 색 분석 JSON을 바탕으로 Aseprite에서 팔레트를 적용하고, 하늘을 차분한 단색 면으로, 구름을 3톤으로 정리했다. 숲·암벽의 어두운 색을 약간 밝게 하여 원경의 대비를 낮췄다.
6. 레이어를 분리하고 PNG·반복 비교본·GIF를 출력한 뒤 저장된 Aseprite를 다시 열어 픽셀 일치를 검증했다.

분리 레이어는 편집을 위한 것으로, 이번 합성 출력과 같은 속도로 이동하는 사용을 기준으로 검수했다. 하늘은 전체 면을 채웠고, 먼 능선은 주봉 뒤에 기본 원경색을 받쳤다. 주봉에 가려진 산 지형 전체를 별도로 재구성한 자산은 아니다. 서로 다른 속도로 이동시키는 추가 패럴랙스 사용은 별도 합성 검수가 필요하다.

`Scripts/`에는 Aseprite 조립·검증 Lua와 이미지 색을 읽어 JSON만 만드는 팔레트 분석 스크립트가 있다. 제외한 도구 양자화 시도는 `Source/Rejected/`에 표시해 보존했다.
