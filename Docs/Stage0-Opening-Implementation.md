## 자동 진행

| 시간(초) | 장면 |
| --- | --- |
| 0~2.8 | 왼쪽 실내에서 의자에 앉아 차를 마심. 창문과 바깥은 검게 가림 |
| 2.8~5.3 | 낮은 울음·엇박자의 반복 울타리 타격. 어둠이 걷히며 밖의 좀비를 발견 |
| 5.3~8.0 | 빈 의자를 남기고 샷건 자세로 전환, 문을 열고 밖으로 이동 |
| 8.0 이후 | 도입 배우를 숨기고 실제 할매/적 웨이브·사격·벨트스크롤 조작 시작 |

시간은 현재 프로토타입 값이다. Enter/건너뛰기로 즉시 같은 Stage 0 사냥에 진입한다. Space는 도입의 시간/오디오를 일시정지·재개한다. 도입 중 전투 HUD/강화를 숨기며 이동·지역 이동·후퇴·강화·피해는 차단한다. 실제 적은 아직 생성하지 않고 도입용 표시 좀비만 보여준다. 전투 시간/처치/보상도 도입 중 증가하지 않는다.

사용자 추가 지시에 따라 울타리 바닥선은 왼쪽 뒤에서 오른쪽 앞으로 약 16도 기울어 내려온다. 말뚝 11개는 수직이고 두 가로대가 대각선으로 이어진다. 좀비는 각 울타리 위치의 바깥쪽에 서며 뒤로 준비→앞으로 손/몸 내밀기→복귀를 1.35초마다 반복한다. 세 좀비의 위상을 엇갈리게 했으며 타격에 맞춰 짧은 충격 표시·가로대 흔들림·타격음을 낸다. 몸과 울타리는 발 깊이에 따라 앞뒤 정렬한다.

도입 종료 시 표시 좀비를 숨기고 같은 세 울타리 위치에 실제 첫 웨이브를 생성한다. Stage 0의 첫 웨이브만 울타리에 머물러 계속 두드리며 할매의 실제 사격·피격·처치·보상 대상이 된다. 울타리 타격은 할매 체력에 피해를 주지 않는다. 추가 스폰도 세 위치에 배치한다. 이후 두 번째 웨이브부터는 기존 추격·근접 공격을 사용한다. 울타리 파괴/내구도나 전역 이동 충돌 규칙은 추가하지 않았다.

이번 Play 세션에서 한 번 본 뒤 일반 재도전은 바로 사냥으로 간다. Editor 컴포넌트의 `Replay Stage 0 Opening` 컨텍스트 메뉴는 도입을 재생하는 새 출정을 시작한다. 앱/Play를 다시 시작하면 도입을 다시 볼 수 있다. 기존 저장 스키마에 영구 시청 플래그를 추가하지 않았다.

정지 씬도 첫 차 장면을 보여준다. 편집용 Belt layout preview 아래에 실내 구도를 저장하며 Play에서는 편집 프리뷰 전체를 숨기고 런타임 표현만 쓴다.

## 좀비 공격 추가

사용자 추가 요청: 좀비가 몸을 뒤로 뺐다가 앞으로 치는 공격.

- 접근 후 0.32초 준비: 발 위치를 뒤로 최대 0.25유닛 빼고 몸도 뒤로 기울임.
- 0.32~0.50초 앞치기: 발을 원래 위치보다 앞으로 최대 0.30유닛 내딛고 몸/팔을 뻗음.
- 0.44초에 한 번만 실제 방향·거리·Y 깊이·장애물을 확인해 피해 판정.
- 0.50~0.85초 복귀. 다음 공격 시작까지 기존 1.35초 간격 유지.
- 준비 중에는 접촉 피해 없음. 목표 깊이를 옮기면 빗나갈 수 있고, 피격/사망/디스폰 시 예약 공격을 취소한다. 풀 재사용 시 타이머·포즈를 초기화한다.

기존 좀비 3프레임에 몸의 이동/기울임/늘임을 조합한 공격이며 별도 손 파츠나 새 스프라이트 시트를 만든 것은 아니다. 실제 발 이동은 기존 장애물/벨트 경계 처리를 거친다.
