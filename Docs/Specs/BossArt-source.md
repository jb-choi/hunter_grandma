## 사용 조건·주의점

- 위 파일들은 각 원본 페이지에서 <b>CC0</b> 라이선스로 배포되는 후보만 선택. 댄서 원본은 GPL·OGA-BY·CC0 선택 라이선스가 병기되어 있으니 적용 라이선스를 프로젝트에 기록할 것.
- 이미지의 크기(64×64)를 <i>보이게 확대</i>하는 것과 실제 에셋 64×64를 만들어 저장하는 것은 다름. 도트 선명도를 위해 \*\*Nearest-neighbor(최근접 이웃)\*\*만 사용하고 부드러운 보간은 사용하지 말 것.
- 한 시트에 여러 인물/프레임이 들어 있는 경우 <b>한 프레임을 추출한 후</b> 투명 64×64 캔버스에 배치.
- 실제 게임 보스는 거대 숙주형 감염체이므로, 위 소형 인간/동물 원본은 실루엣·의상·소품 레퍼런스로 보고 감염된 상태의 큰 보스 표현은 별도 제작해야 함.
- 재배포 제한 때문에 포함하지 못하는 에셋을 섞지 않았으며, 이 페이지의 CC0 파일은 원작자 페이지와 원본 명칭을 보존하여 관리.
