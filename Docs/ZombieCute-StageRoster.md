# 120px 좀비 교체와 Stage 7 확장

2026-10-31 사용자 요청. Stage 0을 유지하고 Stage 7을 추가한다는 답변을 적용했다. 보스 없는 웨이브 소탕 → 다음 스테이지 자동 이동 규칙을 유지한다.

## 아트와 동작

`Assets/Artsource/Drafts/GrandmaShooter120/v002/Monsters_Cute/`의 저장된 정본에서 Aseprite headless로 추출했다.

| 일반 | `zombie_01_normal_120.aseprite` |
| 감염체 | 사용자 지정 `zombie_03_rescue_human_120.aseprite` |

각 Idle 4 / Walk 6 / Run 6 / Attack 6 / Dead 6, 총 84프레임을 `Assets/HunterGrandma/Art/Zombies120/`에 연결한다. 120×120 투명 캔버스, 32 PPU, 피벗 (52,2)px, Point 필터, 원본 팔레트와 시간을 유지한다. 오른쪽을 바라보는 정본을 사용하므로 왼쪽 진행에 flipX를 적용한다.

`ZombieAnimationSet`이 클립과 원본 시간을 제공하고 `ZombieActor`가 기존 풀과 전투 시간에 맞춰 재생한다. 공격은 기존 뒤로 빼기 .32초 → 타격 .18초 → 회복 .35초와 .44초 피해 판정을 유지하며 원본 공격 포즈를 해당 구간에 대응한다. Stage 0의 방문자와 실제 첫 웨이브 모두 지정 감염체가 같은 대각선 울타리를 두드린다.

사망은 원본 Dead 6프레임을 한 번 재생하고 마지막 포즈를 유지한 뒤 페이드한다. 인간형은 누운 인체와 남아 있는 코팅을 보여 주고, 일반/대형은 점액 웅덩이를 보여 준다. 인간 구조·영입 시스템은 추가하지 않으며 기존 단일 처치/보상 경로를 사용한다. 원본 native와 그 아래 원화·파츠·QA는 수정하지 않았다.

## 지도·저장·종료

지도에 Stage 7 동부 외곽 핀을 추가한다. Stage 6 소탕 시 Stage 7이 열리고 자동 이동하며, Stage 7 소탕 후 ALL STAGES CLEAR로 멈춘다. 집 마당의 배경 인덱스를 스테이지 수와 분리해 신규 Stage가 마당으로 표시되지 않도록 했다. 과거 보스 원화 7개는 참조 그대로 보존한다.

기존 v1의 Stage 0~6 기록 7개는 검증 후 빈 Stage 7 기록을 추가한다. 재화·강화·스킬 설정·첫 클리어 시각·과거 포획 기록은 유지한다. Stage 6이 미완료면 Stage 7은 잠긴다. 잘못된 기록 개수나 순서/포획 정합성 오류는 계속 거부한다. 일반 사용자 저장은 검사에서 읽거나 쓰지 않고 별도 Library 프로필을 사용한다.
